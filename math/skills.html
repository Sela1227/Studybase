12 張卡：一張卡管一種能力

每張卡四格一眼看完（看到／想到／做法／小心），配五題：①跟著做 ②半提示 ③④無提示 ⑤混型辨認。第⑤題永遠在測「選方法」。無提示題可先按「第一步提示」——目標是不看提示也寫得出第一步。深入連結通到完整課文，需要時再展開。

技能卡 1

面積差＝平方差

看到正方形面積減正方形面積；剪拼題
想到a² − b²
做法寫成 a²−b² → (a−b)(a+b)
小心題目問邊長，不是答剩餘面積
①跟著做：邊長 2x 剪去邊長 3 的正方形，拼成長方形的兩邊？
(2x)²−3² = (2x−3)(2x+3) → 兩邊就是這兩個因式
剪拼前後面積相等；兩個因式＝兩邊長。
②半提示：16x²−25 = (＿＿)(＿＿)
16x²=(4x)²、25=5²
(4x−5)(4x+5)
③邊長 4x 的正方形剪去邊長 5 的正方形，拼成一邊 4x−5 的長方形，另一邊？
先寫成 a²−b²
(4x−5)(4x+5) → 另一邊 4x+5
④因式分解 9x²−49
(3x−7)(3x+7)
⑤【辨認】x²−6x+9 也用平方差嗎？
三項！先數項數
不是——三項且中間=2·x·3 → 完全平方 (x−3)²
第5題故意混型：先辨認結構再選方法。
深入：第1章 乘法公式／第3章 3-2 實戰（剪拼）
技能卡 2

超過量翻譯

看到「比…多」「超過…」
想到原尺寸 ＝ 總長 − 超過量
做法每個量先寫一行翻譯，再列式
小心是「減」不是「加」；「比…少」方向相反
①跟著做：竿長 L，水平拿超過門寬 2 公尺 → 門寬 = ?
門寬 = L − 2（竿比門寬長 2，門就短 2）
②半提示：同一根竿，垂直拿超過門高 1 公尺 → 門高 = ＿＿
L − 1
③竿 L 超寬 3、超高 2，斜拿剛好等於對角線，列方程式
三行翻譯：門寬/門高/對角線
L² = (L−3)² + (L−2)²
④繩長 R 比樹高多 4 公尺，樹高 = ?
R − 4
⑤【辨認】梯子長 L「比牆矮 2 公尺」，牆高 = ?
誰比誰？方向！
牆高 = L + 2（梯子矮 → 牆高要加回去）
「多」與「少」方向相反——翻譯前先確認誰長誰短。
深入：第4章 實戰・幾何與捨根（竹竿）
技能卡 3

完全平方辨認

看到三項式、首尾都是平方
想到a² ± 2ab + b²
做法驗中間項是否 = 2ab（含符號）
小心中間項有 ＋ 和 − 兩種；參數題兩解都要
①跟著做：x²+10x+25
首 x²、尾 5²；中間 10x = 2·x·5 ✓ → (x+5)²
②半提示：4x²−12x+9 = (2x−＿)²
尾是 3²；驗 2·2x·3
(2x−3)²
③因式分解 9x²+6x+1
(3x+1)²
④4x²+kx+25 可分解成一次式的平方，k = ?
(2x±5)² 的中間項
k = ±20（兩解都要）
⑤【辨認】x²+7x+10 是完全平方嗎？
尾是 (√10)²? 驗中間
不是——2·x·√10 ≠ 7x → 改十字交乘 (x+2)(x+5)
很像但不是——驗中間項就現形。
深入：第3章 乘法公式反用
技能卡 4

兩根範圍篩選

看到未知數是長度、人數、位置
想到解完的每個根都要對條件
做法逐根檢查：為正？在範圍內？合題意？
小心不是「永遠捨負的」——看未知數代表什麼
①跟著做：x 為長度，x²−3x−10 = 0
(x−5)(x+2)=0 → x = 5 或 −2；長度＞0 → x = 5（−2 捨去，理由要寫）
②半提示：x(x−2) = 15 → x = 5 或 −3；x 為邊長 → x = ＿
5
③正方形邊長 x 滿足 x² = 7x，求邊長
提公因式，兩根都列
x = 0 或 7；邊長＞0 → 7
④L² = (L−2)²+(L−1)²，L 為竿長且門寬 L−2 ＞ 0
L = 1 或 5；L＞2 → 5
⑤【辨認】溫度變化 x 滿足 x²−x−6 = 0，x = ?
溫度變化可以是負的嗎？
x = 3 或 −2，兩個都合法
捨根看「未知數代表什麼」，不是機械丟負數。
深入：第4章 解應用題的流程
技能卡 5

根與係數：和與積

看到兩根 α、β 的對稱式或特殊條件
想到x²+px+q：和 = −p、積 = q
做法先寫「和、積」兩行，再變形
小心符號——和是「負的 p」
①跟著做：x²−5x+6 = 0 的兩根和、積
和 = 5、積 = 6（十字驗證：根 2、3 ✓）
②半提示：x²+3x−10 = 0 → 和 = ＿、積 = ＿
和是 −p
和 = −3、積 = −10
③x²−4x+1 = 0 的兩根 α、β，求 α+β 與 αβ
不用解根！
α+β = 4、αβ = 1
④承③風格：x²−5x+6 兩根 α、β，求 α²+β²
(α+β)²−2αβ
25 − 12 = 13
⑤【辨認】x²+px−8 = 0 兩根 a、b 且 a² = b，求 p
條件先配「積」
ab = a³ = −8 → a = −2、b = 4 → p = −(a+b) = −2
特殊條件先用積或和縮小，不硬解。
深入：第4章 實戰・根與係數（含轉換表）
技能卡 6

括號 ≠ 因式

看到(…)(…) ± 一個數，問因式
想到先展開合併，再重新分解
做法展開 → 整理 → 分解；因式只認分解後的
小心原式看得到的括號，多半已不是因式
①跟著做：(x+2)(x+3) − 6 的因式？
展開：x²+5x+6−6 = x²+5x = x(x+5) → 因式是 x 與 x+5（(x+2) 不是！）
②半提示：(x+1)(x+4) − 4 = x²+5x = ＿＿
提公因式
x(x+5)
③(x+2)(2x+1) − 5 的因式？
先展開
2x²+5x−3 = (2x−1)(x+3)
④4a² − (a+3)(a−2) − 10 的因式？
3a²−a−4 = (3a−4)(a+1)
⑤【辨認】(x+3)² 的因式是 x+3 嗎？
後面有沒有「±其他數」？
是——它已是分解完成式，沒有被加減破壞
只有「括號±其他數」才要先展開；純乘積形不用。
深入：第3章 實戰題型（何者是因式）
技能卡 7

答所問：x 不是終點

看到應用題、「求正確答案／面積／周長」
想到解出 x 只是半路
做法最後一行回答題目的「名詞」
小心題目問什麼？x？面積？周長？答案？
①跟著做：正數 n 平方減 24＝2n+24，求「正確答案」
n²−2n−48=0 → n=8 → 題目問「答案」＝ n²−24 = 40（不是 8！）
②半提示：正方形邊 x 滿足 x²=4x（面積＝周長數值），求「面積」
x 解出後還有一步
x=4 → 面積 = 16
③長方形寬 x、長 x+3、面積 40，求「周長」
x=5 → 周長 = 2(5+8) = 26
④某正數的平方減 5 等於它的 4 倍，求「平方減 5 的值」
x²−4x−5=0 → x=5 → 值 = 20
⑤【辨認】x²=49 且 x 為正，求 x
這題問的是誰？
7——這題問的就是 x 本身，不用再轉
答題前固定自問：問的是未知數，還是由它算出的量？
深入：第4章 實戰・誤算問題
技能卡 8

不能除以未知數

看到等式兩邊都有 x 的因式
想到移到同邊、提公因式
做法x(…) = 0 → 零乘積，兩根都寫
小心除以 x 會把 x=0 這個根丟掉
①跟著做：x² = 5x
移項提公因式：x(x−5) = 0 → x = 0 或 5（除以 x 只剩 5，丟了一根）
②半提示：3x² = 12x → 3x(x−＿) = 0
3x(x−4)=0 → x = 0 或 4
③解 4x − 3x² = 0
提公因式
x(4−3x)=0 → x = 0 或 4/3
④解 2x² = x
x(2x−1)=0 → x = 0 或 1/2
⑤【辨認】x² = 5x + 6 也提公因式嗎？
有常數項嗎？
不行——移項後 x²−5x−6 有常數項 → 十字交乘 (x−6)(x+1) → 6、−1
「兩邊都有 x 因式」才提；有常數項就走十字。
深入：第4章 實戰・步驟找錯
技能卡 9

配方：B 的一半再平方

看到x² + Bx 要配成完全平方
想到加 (B/2)²
做法先把 B 框出來（含符號、含分數）再除 2 平方
小心B=−3/4 時加 9/64，不是 (3/2)²；係數非 1 先除
①跟著做：x²+6x 配方
B=6 → 加 (6/2)² = 9 → (x+3)²
②半提示：x²−8x+＿ = (x−4)²
B=−8
加 16
③x²+3x 要加多少？
B=3，一半是分數也照做
(3/2)² = 9/4
④x²−(3/4)x 要加多少？
(3/8)² = 9/64
⑤【辨認】2x²+8x 配方，第一步？
係數是 1 嗎？
先除以 2 → x²+4x → 加 4
B 的規則只對「x² 係數 = 1」有效。
深入：第4章 配方法
技能卡 10

分解前四項檢查

看到任何要因式分解的式子
想到降冪 → 提公因式 → 處理負號/分數 → 選法
做法四項掃完再動手
小心別急著十字交乘——怪式子先整形
①跟著做：12−4x−x²
降冪提負：−(x²+4x−12) = −(x+6)(x−2)
②半提示：2x²+10x+12 = 2(x²+5x+6) = 2(＿)(＿)
先提 2
2(x+2)(x+3)
③因式分解 ½x² + (3/2)x − 5
提公分母分之一
½(x²+3x−10) = ½(x+5)(x−2)
④因式分解 10−3x−x²
−(x+5)(x−2)
⑤【辨認】x²+5x−6 需要整形嗎？
四項檢查掃一遍
不用——已是標準型，直接十字 (x+6)(x−1)
檢查通過就直接做，不是每題都要整形。
深入：第3章 實戰題型二
技能卡 11

畢氏翻譯表

看到直角、距離、斜邊、對角線
想到斜邊² ＝ 股² ＋ 股²
做法三行翻譯表：兩股、斜邊各是誰
小心先認清誰是斜邊（對著直角的那邊）
①跟著做：兩股 3、4，斜邊？
斜² = 9+16 = 25 → 5
②半提示：兩股 6、8 → 斜邊 = ＿
10
③斜邊 13、一股 5，另一股？
另一股² = 斜² − 股²
√(169−25) = 12
④方格紙上從 A 往右 2 格、往上 3 格到 B，AB = ?
格數就是兩股
√(4+9) = √13
⑤【辨認】三邊 5、12、13 是直角三角形嗎？
這是「逆」著用
25+144 = 169 ✓ → 是（逆定理）
性質：直角→等式；逆定理：等式→直角。
深入：第2章 畢氏定理與實戰
技能卡 12

塊數當係數

看到拼板、紙板、代數磚
想到a 塊 x²＋b 塊 x＋c 塊 1 → ax²+bx+c
做法分解 → 兩因式＝兩邊長 → 代入數字
小心面積相同只是必要條件——要真的分解得動
①跟著做：1 塊 x²、3 塊 x、2 塊 1 拼成長方形，兩邊？
x²+3x+2 = (x+1)(x+2) → 兩邊 x+1 與 x+2
②半提示：2x²+5x+2 = (2x+1)(＿)
(x+2)
③6 塊邊長 4 正方形、7 塊 4×1、2 塊 1×1，拼成的長方形？
設 x=4 分解再代回
6x²+7x+2 = (3x+2)(2x+1) → 14 × 9
④3 塊 x²、7 塊 x、2 塊 1，兩邊？
(3x+1)(x+2)
⑤【辨認】7π²+16π+12 拼得成長方形嗎？
可分解嗎？看判別式
16²−4·7·12 = −80 ＜ 0 → 拼不成
可拼 ⇔ 可分解；面積對不代表拼得成。
