12 張卡，每張只練一件事

每張卡開頭四格，講的是「看到題目的那三秒鐘，腦子裡該閃過什麼」。接著五題：① 跟著做 → ② 有小提示 → ③④ 自己來（卡住可以按「第一步提示」，不丟臉，這就是它存在的目的）→ ⑤ 小心陷阱（長得很像、但方法不同）。每題做完點一下下面的四個鈕之一（對或錯要誠實點——點錯的不扣分，只會讓卡片知道該再回來找你）。卡片下面還有兩題「回鍋」，是給之後的自己做的，現在不用動。

平方差：面積相減的臉

看到什麼題目長得像「一個正方形面積 減 另一個正方形面積」，或是剪一塊拼成長方形
心裡想「喔，這是 a² − b² 的臉。」
動手第一步先老實寫成 a² − b²，再拆：(a−b)(a+b)
最容易掉的坑題目問「邊長」的話，答案是那兩個括號，不是整塊面積
① 跟著做一次：邊長 2x 的正方形剪掉邊長 3 的，拼成長方形，兩邊是多少？
剪來拼去，面積都沒變：(2x)²−3² = (2x−3)(2x+3)
所以長方形的兩邊就是 2x−3 和 2x+3——不用畫圖硬算
② 小提示版：16x²−25 = (＿＿)(＿＿)
16x² 是誰的平方？25 呢？
(4x−5)(4x+5)
做完點一個：
③ 自己來：邊長 4x 的正方形剪掉邊長 5 的，拼成一邊是 4x−5 的長方形，另一邊？
先寫成 a²−b²
(4x−5)(4x+5) → 另一邊 4x+5
做完點一個：
④ 自己來：因式分解 9x²−49
(3x−7)(3x+7)
做完點一個：
⑤ 小心陷阱：x²−6x+9 也是平方差嗎？
先數一下有幾項
不是喔——它有三項，而且中間 6x = 2·x·3，是完全平方 (x−3)²
第⑤題永遠在考「先認臉再動手」。三項的臉不是平方差的臉。

翻譯機：「比…多」「超過…」

看到什麼題目說「竿子比門寬多 2」「超過高度 1」這種話
心裡想「先別列式——一句一句翻成算式。」
動手第一步每句話寫一行：原尺寸 ＝ 總長 − 超過的量
最容易掉的坑「多」是減回去、「少」是加回去——先想清楚誰比較長
① 跟著做一次：竿長 L，水平拿會超過門寬 2 公尺。門寬多少？
竿比門長 2 → 門比竿短 2 → 門寬 = L − 2
就這一行。翻譯題不急著解，先把每個量都翻完。
② 小提示版：同一根竿，垂直拿超過門高 1 公尺 → 門高 = ＿＿
L − 1
做完點一個：
③ 自己來：竿 L 超寬 3、超高 2，斜著拿剛好是門的對角線。列出方程式（不用解）
三行：門寬、門高、對角線各是什麼
門寬 L−3、門高 L−2、對角線 L → L² = (L−3)² + (L−2)²
做完點一個：
④ 自己來：繩子長 R，比樹高多 4 公尺。樹高？
R − 4
做完點一個：
⑤ 小心陷阱：梯子長 L，「比牆矮 2 公尺」。牆高？
這次是誰比較長？
牆比梯子高 → 牆高 = L + 2
「多」和「少」方向相反——翻譯前先站好隊：誰長誰短。
做完點一個：
隔天 回鍋A：竿 L 超寬 5、超高 3，斜拿剛好對角線，列方程式
L² = (L−5)² + (L−3)²

完全平方的臉

(3x+1)²

(2x±5)² 的中間項長怎樣？
±2·2x·5 → k = 20 或 −20（兩個都要）

驗中間：2·x·？

看到什麼題目講「兩根 α、β」，要你算它們的組合
心裡想「先寫和、積兩行，說不定根本不用解根。」
動手第一步x²+px+q = 0：和 = −p、積 = q（和是負的 p！）
最容易掉的坑符號——十個錯有九個錯在「和」的負號
① 跟著做一次：x²−5x+6 = 0 兩根的和與積
和 = 5、積 = 6（偷驗一下：根是 2 和 3，2+3=5 ✓ 2×3=6 ✓）
② 小提示版：x²+3x−10 = 0 → 和 = ＿、積 = ＿
和是 −p
和 = −3、積 = −10
做完點一個：
③ 自己來：x²−4x+1 = 0 的兩根 α、β，求 α+β 與 αβ
根很醜（帶根號）——所以更不要解！
α+β = 4、αβ = 1
做完點一個：
④ 自己來：x²−5x+6 = 0 兩根 α、β，求 α²+β²
α²+β² = (α+β)² − 2αβ
25 − 12 = 13
做完點一個：
⑤ 小心陷阱：x²+px−8 = 0 兩根 a、b，且 a² = b，求 p
特殊條件先跟「積」握手
積：a·a² = a³ = −8 → a = −2、b = 4 → p = −(和) = −2
根有特殊條件時，先用積（或和）把它逼出來，別硬解方程式。

看到什麼(…)(…) 後面還加或減一個數，然後問因式
心裡想「那個括號被破壞了——先展開再說。」
動手第一步展開 → 合併 → 重新分解；因式只認分解後的

① 跟著做一次：(x+2)(x+3) − 6 的因式？
展開：x²+5x+6−6 = x²+5x = x(x+5)
因式是 x 和 x+5——(x+2) 已經不是了（被 −6 破壞）
② 小提示版：(x+1)(x+4) − 4 = x²+5x = ＿＿
有公因式
x(x+5)
做完點一個：
③ 自己來：(x+2)(2x+1) − 5 的因式？
先展開合併
2x²+5x−3 = (2x−1)(x+3)
做完點一個：
④ 自己來：4a² − (a+3)(a−2) − 10 的因式？

看到什麼等式兩邊都帶著 x，例如 x² = 5x

如果直接除以 x，只剩 x=5——考卷上少一個根就是少一半分。

3x(x−4)=0 → x = 0 或 4

x(4−3x)=0 → x = 0 或 4/3

④ 自己來：解 2x² = x

分解前先掃四格

看到什麼任何一題「因式分解」
心裡想「先別急著十字交乘——掃四格。」
動手第一步① 降冪排好 ② 提公因式 ③ 處理負號或分數 ④ 再選方法
最容易掉的坑怪式子（負首項、分數）整形完，多半就變回熟臉
① 跟著做一次：12−4x−x²
降冪：−x²−4x+12 → 提負號：−(x²+4x−12) → 十字：−(x+6)(x−2)
② 小提示版：2x²+10x+12 = 2(x²+5x+6) = 2(＿)(＿)
先提 2
2(x+2)(x+3)
做完點一個：
③ 自己來：因式分解 ½x² + (3/2)x − 5
提「公分母分之一」
½(x²+3x−10) = ½(x+5)(x−2)
做完點一個：
④ 自己來：因式分解 10−3x−x²
−(x+5)(x−2)
做完點一個：
⑤ 小心陷阱：x²+5x−6 需要整形嗎？
四格掃一遍
不用——已經是標準臉，直接十字 (x+6)(x−1)
掃四格是「檢查」不是「儀式」——通過就直接動手。
