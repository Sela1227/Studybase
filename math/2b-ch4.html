國二下 · 第4章 平行與四邊形

36 分那次的範圍——這次把它一格一格拿回來

這章是上次段考最痛的地方。它其實只有三個層：平行線的角（4-1）→ 平行四邊形的性質與判別（4-2）→ 特殊四邊形各自多了什麼（4-3）。每一層都建在第3章的全等上；只要照順序走，性質一句一句用，這章是能整章拿回來的。

前置：第3章（全等、內外角）預計 40 分鐘／節依賴鏈：第3章 → 本章 → 國三相似形
4-1 · 認角

一條截線切兩條線：同位角、內錯角、同側內角

名稱位置關係圖中例子認字口訣
同位角截線同側、兩線同方位∠1 與 ∠5像 F 字形
內錯角兩線之間、截線兩側∠4 與 ∠6像 Z 字形
同側內角兩線之間、截線同側∠4 與 ∠5像 C（ㄈ）字形
F、Z、ㄈ 只是快速辨認的口訣，不是正式定義。圖形一旋轉、截線一傾斜，字形就可能看不出來。正式判斷檢查三件事：① 角在兩直線之間還是外側　② 在截線的同側還是異側　③ 在兩個交點的相對位置是否相同。口訣猜不準時，回這三步。
兩直線被同一條截線所截時：兩線平行 → 各組同位角相等、內錯角相等、同側內角互補；反之，只要有「一組」符合其中任一關係，即可判定兩線平行
記清楚方向：「平行 → 角的關係」是性質；「一組角的關係 → 平行」是判定。做題第一步先分辨題目給的是哪一邊。
前提是平行！兩條不平行的線也有同位角、內錯角——只是它們不相等。用角的關係前，先確認題目給了平行（或先證出平行）。
4-1 · 求角

認出 F、Z、ㄈ，角度就出來

例①【核心必會】L₁∥L₂，某同位角 = 65°，它的同位角、內錯角、同側內角各是？
同位角 = 65°；內錯角 = 65°；同側內角 = 180−65 = 115°
三句性質各用一次。同側內角是「互補」不是「相等」——這是 4-1 最常見的失分。
例②【進階】摺線題：L₁∥L₂，中間折了一個點 P，∠1=40°（靠 L₁）、∠2=35°（靠 L₂），求 ∠P
過 P 作一條與 L₁ 平行的輔助線（紅虛線）——∠P 被切成上下兩塊
P 處的大角被拆成上下兩塊：上角與 ∠1 是內錯角 = 40°；下角與 ∠2 是內錯角 = 35° → ∠P = 40+35 = 75°
「中間有轉折點」的標準動作：過轉折點補一條平行線，把一個大角拆成兩個 Z 字形。

觀念辨識（答錯可再選）

1. L₁∥L₂ 時，同側內角的關係是？
同位角、內錯角才相等；同側內角是互補。
再看一次，選出正確的。
2. 兩條「不平行」的線被截線切，同位角會？
角的相等關係是平行專屬的；不平行時只是有名字、沒有等式。
再看一次，選出正確的。

基本計算（L₁∥L₂）

① 一組同位角分別為 2x+10° 與 3x−15°，求 x
同位角相等：2x+10 = 3x−15 → x = 25
② 一組同側內角分別為 x° 與 2x+30°，求 x
互補：x + 2x + 30 = 180 → x = 50
③ 內錯角一個是 72°，另一個是多少？對應的同側內角呢？
內錯角 = 72°；同側內角 = 180−72 = 108°
④【進階】摺線：∠1 = 50°、∠2 = 28°，求轉折點的 ∠P
過 P 補平行輔助線 → ∠P = 50 + 28 = 78°
⑤【判定】一組內錯角為 3x+5° 與 5x−35°。若兩角相等，求 x，並說明兩直線的關係
3x+5 = 5x−35 → x = 20（兩角各 65°）
結論要用文字寫出：因為有一組內錯角相等，所以 L₁ ∥ L₂（4-1 判定）。
方向反過來的題：不是「平行→求角」，是「角相等→判定平行」。結論那句話是得分點。
⑥【判定】L₁∥L₂，一組同側內角為 2x+20° 與 4x−20°，求 x；並反過來說明：若只知這兩角互補，能得到什麼？
(2x+20)+(4x−20) = 180 → x = 30（兩角 80°、100°）
反向：因為同側內角互補，所以兩直線平行——同一條等式，兩個方向都要會說。

4-2 · 性質

平行四邊形：一個定義、四條性質

定義：兩雙對邊分別平行的四邊形。由定義（加上第3章的全等），可以推出四條性質。

#性質寫成等式
1對邊相等AB = DC、AD = BC
2對角相等∠A = ∠C、∠B = ∠D
3鄰角互補∠A + ∠B = 180°
4對角線互相平分AO = OC、BO = OD
證明一【核心必會】對邊相等、對角相等（性質 1、2）
連對角線 AC，比較 △ABC 與 △CDA：
AB∥DC → ∠BAC = ∠DCA（內錯角）；AD∥BC → ∠BCA = ∠DAC（內錯角）；AC 共用
→ △ABC ≅ △CDA（ASA）→ 對應邊 AB=CD、BC=DA；對應角 ∠B=∠D（∠A=∠C 由兩組內錯角相加）
證明二【進階】對角線互相平分（性質 4）——換一組三角形
設對角線交於 O，比較 △AOB 與 △COD：
AB∥DC → ∠OAB = ∠OCD、∠OBA = ∠ODC（兩組內錯角）；AB = CD（證明一的結果）
→ △AOB ≅ △COD（ASA）→ AO=OC、BO=OD
兩個證明用的是不同的三角形：證明一切對角線比大三角形；證明二比對角線交點旁的小三角形，而且要先用證明一的結果——證明是一層一層疊的，不是一句「內錯角＋ASA」帶過。性質 3（鄰角互補）則直接來自 4-1 的同側內角。
注意性質 4 說的是「互相平分」，不是「兩條對角線一樣長」——一樣長是矩形才有的（4-3）。
一條對角線把平行四邊形分成兩個全等的三角形 → [△ABC] = [△CDA] = 平行四邊形面積的一半
例【核心必會】平行四邊形面積 48，連一條對角線後每個三角形面積？
48 ÷ 2 = 24
這是證明一的直接紅利（全等 → 等面積），也是之後複合面積題的常用工具。
例【核心必會】平行四邊形 ABCD 中 ∠A = 70°，求其他三個角
∠C = ∠A = 70°（對角）；∠B = ∠D = 180−70 = 110°（鄰角互補）
知道一個角，全部四個角就都知道了。
4-2 · 判別

反過來：怎麼證一個四邊形是平行四邊形？

#判別條件（滿足其一即可）
1兩雙對邊分別平行（定義）
2兩雙對邊分別相等
3一雙對邊平行且相等
4兩雙對角分別相等
5對角線互相平分
經典陷阱：「一雙對邊平行、另一雙對邊相等」不能判定——等腰梯形正是反例（上下底平行、兩腰相等，但不是平行四邊形）。判別 3 要的是同一雙對邊又平行又相等。
例【核心必會】已知四邊形 ABCD 中 AO=OC、BO=OD（O 為對角線交點），是平行四邊形嗎？
對角線互相平分 → 判別 5 → 是
性質和判別是「雙向門」：性質是「已知是平四，推出等式」；判別是「已知等式，證明是平四」。考題就在考你分清方向。
判別證明①【進階】已知 AO=OC、BO=OD，完整證明 ABCD 是平行四邊形
比較 △AOB 與 △COD：AO=OC、BO=OD（已知）、∠AOB = ∠COD（對頂角）→ SAS 全等
→ ∠OAB = ∠OCD（對應角）——它們是 AB、DC 被 AC 所截的內錯角 → 內錯角相等 → AB∥DC
同理比較 △AOD 與 △COB → AD∥BC → 兩雙對邊分別平行 → ABCD 是平行四邊形 ∎
證明的骨架：全等（第3章）→ 對應角相等 → 內錯角相等 → 平行（4-1 判定）。第3、4章在這裡真正接上。
判別證明②【進階】已知 AB∥DC 且 AB=DC，證明 ABCD 是平行四邊形
連 AC。△ABC 與 △CDA：AB=CD（已知）、∠BAC=∠DCA（AB∥DC 的內錯角）、AC 共用 → SAS 全等
→ ∠BCA = ∠DAC（對應角）→ 內錯角相等 → AD∥BC → 兩雙對邊平行 ∎
這就是判別 3「一雙對邊平行且相等」成立的理由——也再次看到為什麼「平行的一雙」和「相等的一雙」必須是同一雙。

4-3 · 家族

加一個條件：既能判別，也會多出性質

圖形是什麼多出來的性質
矩形有一個直角的平行四邊形四個角都 90°；對角線等長
菱形有一雙鄰邊相等的平行四邊形四邊等長；對角線互相垂直平分、且平分頂角
正方形既是矩形又是菱形兩邊的性質全包
家族關係：正方形 ⊂ 矩形 ⊂ 平行四邊形，正方形 ⊂ 菱形 ⊂ 平行四邊形。所以「矩形一定是平行四邊形」對；「平行四邊形一定是矩形」錯——包含方向不能反。
要判定成…先確認是平行四邊形，再符合下列任一
矩形有一個直角；或 對角線等長
菱形有一雙鄰邊相等；或 對角線互相垂直；或 一條對角線平分一個頂角
正方形矩形＋一雙鄰邊相等；或 菱形＋一個直角；或 平四＋對角線等長且互相垂直
反向陷阱：單獨看到「對角線等長」或「互相垂直」不能直接判定——對角線等長的等腰梯形不是矩形；對角線互相垂直的箏形不是菱形。判別的前提是先知道它是平行四邊形（或題目另給足夠條件）。性質不能無條件反過來用。
例①【核心必會】菱形對角線長 6、8，求邊長與面積
對角線互相垂直平分 → 邊是直角三角形的斜邊，兩股 = 3、4
邊長 = √(3²+4²) = 5（畢氏定理，國二上第2章回鍋）
面積 = 對角線相乘 ÷ 2 = 6×8÷2 = 24
菱形題八成都靠「對角線互相垂直平分」切出四個全等的直角三角形。
例②【核心必會】矩形對角線 AC = 3x−1、BD = x+7，求 x
矩形對角線等長：3x−1 = x+7 → x = 4（對角線 = 11）
4-3 · 梯形與整理

梯形只有一雙平行；一張表看完全家族的對角線

梯形：恰有一雙對邊平行　；　等腰梯形：兩腰相等 → 同一底上的兩底角相等、對角線等長
本教材依課本約定：梯形是「恰有一雙」對邊平行的四邊形——所以平行四邊形（含矩菱正）不算梯形，家族界線清楚。
梯形中線（連兩腰中點）：中線 ∥ 兩底，且 中線長 = (上底 + 下底) ÷ 2
例【核心必會】上底 8、下底 14，求中線；又若中線 12、上底 7，求下底
中線 = (8+14)/2 = 11
反求：下底 = 2×12 − 7 = 17
中線是「兩底的平均」——反求就把平均式倒回去（×2 再減）。這是梯形最典型的計算題。
例【核心必會】等腰梯形 ABCD（AD∥BC），∠B = 65°，求其餘三角
同底 ∠C = 65°（底角相等）；∠A = ∠D = 180−65 = 115°（同側內角互補）
對角線性質平行四邊形矩形菱形正方形等腰梯形
互相平分✓✓✓✓✗
等長✗✓✗✓✓
互相垂直✗✗✓✓✗
這張表是 4-3 選擇題的答案庫——「哪個圖形的對角線一定…」全在這裡。注意等腰梯形對角線等長但不互相平分（它不是平行四邊形）。

基本計算

① 菱形對角線 10、24，求邊長與面積
兩股 5、12 → 邊長 = 13；面積 = 10×24÷2 = 120
② 矩形 ABCD 對角線交於 O，AO = 7，求 BD
對角線等長且互相平分 → AC = 14 = BD → BD = 14
③ 等腰梯形一個底角 72°，求其餘三角
同底另一角 72°；另一底兩角各 108°
④ 梯形上底 6、下底 16，求中線；又若中線 10、下底 13，求上底
中線 = (6+16)/2 = 11；上底 = 2×10 − 13 = 7
⑤【判定】ABCD 是平行四邊形且 AC = BD，它是什麼圖形？若再加 AC ⊥ BD 呢？
平四＋對角線等長 → 矩形；再加互相垂直 → 等長且垂直 → 正方形
判別的前提「是平行四邊形」已由題目給出，才能用對角線條件加碼。
⑥【陷阱】某四邊形的對角線等長，能斷定它是矩形嗎？
不能——等腰梯形的對角線也等長，但它不是矩形（甚至不是平行四邊形）。要先確認是平行四邊形。
⑦ 正方形對角線長 8，求面積
正方形也是菱形 → 面積 = 8×8÷2 = 32
不用先求邊長——菱形與正方形的面積都可用「兩對角線乘積 ÷ 2」（因為對角線互相垂直，把圖形切成四個直角三角形）。
