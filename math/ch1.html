前置快篩：乘方、正負號、分配律、單項式乘法、同類項合併預計 40 分鐘／節當「從頭學」設計，不預設你記得
乘法公式 · 和的平方

(a+b)2 到底等於什麼？

先講一個超常見的錯：很多人以為 (a+b)2 = a2+b2。這是錯的。在看公式前，先確認兩個基礎動作。

開始前先記住兩件事

① 平方的意思：(a+b)2 是 (a+b)(a+b)，不是把括號裡各自平方。

② 兩個括號相乘：第一個括號的每一項，都要分別乘第二個括號的每一項：

(a+b)(a+b) = a·a + a·b + b·a + b·b
公式裡的 a、b 代表「一整項」：不一定是單一字母，可以是一個數、一個單項式、或整個式子。例如 (2x−5)2 要把 2x 整體當成 a。
圖
邊長 (a+b) 的正方形，切成四塊：a2、ab、ab、b2
圖以正數示意；公式對正數、負數與 0 都成立
代數
(a+b)2 = (a+b)(a+b) = a2 + ab + ab + b2 = a2 + 2ab + b2
白話

平方一個「和」，中間會多出兩塊 ab（合起來 2ab）。漏掉這個 2ab，就是最常見的錯。

(a+b)2 = a2 + 2ab + b2
例：展開 (x+3)2
= x2 + 2·(x)·(3) + 32 = x2 + 6x + 9
a=x、b=3。中間 6x 就是 2ab=2·x·3。
常見錯誤：把 (x+3)2 寫成 x2+9，漏掉中間 6x。看到平方，先問「中間那項呢？」
乘法公式 · 差的平方

(a−b)2 只差一個符號

跟和的平方幾乎一樣，只是中間那項變號。看圖就懂為什麼是 −2ab。

圖
從 a2 扣掉兩條 ab，右下角的 b2 被扣了兩次，要補回來：a2 − ab − ab + b2 = (a−b)2
圖以正數（且 a > b）示意；公式對正數、負數與 0 都成立
代數
(a−b)2 = (a−b)(a−b) = a2 − ab − ab + b2 = a2 − 2ab + b2
白話

跟和的平方長得一樣，只有中間那項變減號。最後一項 b2 還是加的（負負得正）。

(a−b)2 = a2 − 2ab + b2
例：展開 (2x−5)2
= (2x)2 − 2·(2x)·(5) + 52 = 4x2 − 20x + 25
a=2x，所以 a2=(2x)2=4x2，係數 2 也要平方。
常見錯誤：(2x−5)2 第一項寫成 2x2。要 (2x)2=4x2，把 2x 整體當 a。
乘法公式 · 平方差

同兩項、一加一減，中間才會抵消

同樣的兩項，一個相加、一個相減時，相乘的中間兩項才會互相抵消，只剩兩個平方相減。

圖 · 切割重排
左：邊長 a 的正方形挖掉角落 b2，把下面那塊（綠）切下來、轉 90° 移到右邊；右：重排成長 (a+b)、寬 (a−b) 的長方形。所以 a2−b2 = (a+b)(a−b)。
圖以正數（且 a > b）示意；公式對正數、負數與 0 都成立
代數
(a+b)(a−b) = a2 − ab + ab − b2 = a2 − b2 （中間 −ab+ab 抵消）
白話

只有「同兩項、一加一減」中間才抵消。像 (x+5)(x−3) 這種兩項不同的，不會抵消，不能用平方差。

(a+b)(a−b) = a2 − b2
例：展開 (x+4)(x−4)
= x2 − 42 = x2 − 16
符合「同兩項、一加一減」，直接套平方差。
用之前先確認：兩括號要「同兩項、只差 +/−」。(x+4)(x+4) 是和的平方；(x+4)(x−3) 兩者都不是。
乘法公式 · 速算（數字版）

公式換上數字外衣：考卷上的速算題

這種題型在你的考卷上出現過。它們考的不是新東西——就是這三個公式，只是把 a、b 換成數字。訣竅只有一個：把數字改寫成「好算的基準 ± 一點點」。

選基準：挑最近的整十、整百，或兩數的正中間
例①【基礎】1022
= (100 + 2)2 = 1002 + 2·100·2 + 22 = 10000 + 400 + 4 = 10404
基準選 100。中間 2ab=400 一樣不能漏。
例②【核心必會】帶分數平方：(60⅔)2 = 602 + a，求 a
(60 + ⅔)2 = 602 + 2·60·⅔ + (⅔)2 = 602 + 80 + 4/9
a = 80 4/9
這題最容易選成 4/9——那就是漏了中間 2ab = 2·60·⅔ = 80。帶分數平方跟 (a+b)² 一模一樣，中間那項照樣在。
例③【進階】選基準：2004 × 1996 − 19952 的十位數字
2004×1996 = (2000+4)(2000−4) = 20002 − 42 = 3,999,984
19952 = (2000−5)2 = 4,000,000 − 20,000 + 25 = 3,980,025
相減 = 19,959 → 十位數字 = 5
基準不只一種。本例選 2000（兩數正中間），是因為「一加一減」的平方差外觀最明顯；連 1995² 也能再用一次差的平方。
另一種一樣正確的解法（以 1995 為基準）：2004=1995+9、1996=1995+1 → (1995+9)(1995+1) − 1995² = 1995² + 10·1995 + 9 − 1995² = 19,950 + 9 = 19,959。抓「共同基準」的想法是對的——展開後把 1995² 消掉，剩下的整理好就是答案。兩條路都通，挑你看得順的。
例④【挑戰・兩層公式】在數字裡認出公式：290×288/289 + 1/289 + 2×17×23 + 529
第一步・分數合併：290×288 = (289+1)(289−1) = 2892 − 1
(2892 − 1)/289 + 1/289 = (2892 − 1 + 1)/289 = 2892/289 = 289
第二步・認出平方：289 = 172、529 = 232，剩下的排成三塊——
289 ＋ 2×17×23 ＋ 529
＝ 172（a2）　＋　2·17·23（2ab）　＋　232（b2）
= (17 + 23)2 = 402 = 1600
兩層公式：分數那邊是平方差；後面是「a²+2ab+b² 的長相」——看到「某數² + 2×甲×乙 + 另一數²」就要想到完全平方。背 17²=289、23²=529 這些常見平方數會快很多。
速算題三步：① 選基準（整十百／兩數中點）② 改寫成 (基準±小)，認出是哪個公式 ③ 套公式，中間項不漏。認不出公式就會退回硬算——又慢又容易錯，這正是這種題想考的。

多項式加減 · 名詞

先把名字認清楚

不用背定義，先看懂這幾個詞，後面才知道「同類」是什麼意思。

多項式 = 一個或多個「單項式」相加減，且文字的指數都是 0、1、2、3…（不能是負數或分數）

例如 3x2 − 5x + 2 是多項式；單獨一項 3x2 也算多項式。但 x−1（＝1/x）、√x 這種指數是負數或分數的，不是多項式。

詞意思在 3x2 − 5x + 2 裡
項被加減分開的每一塊3x2、−5x、2 共三項
係數項前面的數字3、−5
常數項沒有文字的項2
數字的平方不是次數：42+2x 裡的 42 只是 16（常數），所以 42+2x = 16+2x 是一次多項式，不是二次。次數只看文字的指數，跟數字的指數無關。
次數怎麼算：一個單項式的次數是「各文字指數的總和」——例如 3a2b 是 2+1=3 次。多項式的次數，是各項中最高的那個次數（3x2−5x+2 是二次）。目前只有一個 x 的式子，一項的次數就等於 x 的指數。
同類項 = 文字部分「完全一樣」的項

3x 和 −5x 是同類（都是 x）；3x 和 3x2 不是同類（一次 vs 二次）。這個判斷是下一課的關鍵。

多項式加減 · 合併同類項

同類才能合，係數相加、文字不變

合併同類項是多項式最基本的動作。

白話

3 個 x 加 2 個 x，是 5 個 x——像 3 顆蘋果加 2 顆蘋果。但蘋果不能跟橘子合：x 和 x2 不同類，不能加。

代數
3x + 2x = (3+2)x = 5x　係數相加，x 不動
3x + 2x2 不同類，不能合
分類
同類（可合）不同類（不可合）
7a 與 −2a7a 與 7b
x2 與 4x2x2 與 x
5 與 −3（常數）5 與 5x
例：合併 4x + 3 − x + 5
= (4x − x) + (3 + 5) = 3x + 8
同類擺一起：x 類合成 3x，常數合成 8。不同類的分開寫。
常見錯誤：把 3x + 8 再算成 11x。x 類和常數不同類，答案就是 3x + 8。
多項式加減 · 去括號

減號去括號，裡面全變號

這是整個第1章最容易掉分的地方，慢慢看。

− ( a − b + c ) = − a + b − c

括號前面是 加號：直接拿掉，裡面不變。
括號前面是 減號：括號拿掉時，裡面每一項都要變號——不是只有第一項。

例：(3x2 + 2x − 1) − (x2 − 4x + 5)
= 3x2 + 2x − 1 − x2 + 4x − 5
= 2x2 + 6x − 6
紅色是重點：第二個括號前面是減號，x2→−x2、−4x→+4x、+5→−5，三項全變號，再合併。
最常見的錯：減號只把第一項變號，後面照抄。這一項沒變號，後面整題就會算錯。去減號括號時，每一項都盯著變號。
多項式加減 · 係數條件題（實戰）

考卷上的進階題：條件都藏在「係數」裡

這幾種題型在你的考卷上出現過。它們看起來很難，其實心法只有兩步：① 先整理成 □x²＋□x＋□　② 把題目條件翻譯成「哪個係數＝0、哪個≠0、哪些要相等」。

題目說…翻譯成係數條件
是「一次」多項式x2 係數＝0，且 x 係數 ≠ 0
是「零次」多項式x2、x 係數都＝0，且常數 ≠ 0
兩個多項式 A＝B同次項的係數各自相等
結果只有 n 個相異的項多出來的那些項，係數＝0
例①【核心必會】(a−2)x2 + (a+b−5)x + 5 是 x 的一次多項式，且 x 項係數為 3，求 2a+3b
「一次」→ x2 係數＝0：a − 2 = 0 → a = 2
「x 係數為 3」→ a + b − 5 = 3 → 2 + b − 5 = 3 → b = 6
2a + 3b = 4 + 18 = 22
兩個條件、兩條式子、逐一解出。最容易的失誤是只用了一個條件就急著代入。
例②【核心必會】(x3−3x2−2) − (3−ax2+x) 的結果只有三個相異的項，求 a
去括號（每項變號）：x3 − 3x2 − 2 − 3 + ax2 − x
整理：x3 + (a−3)x2 − x − 5　（目前四種項）
只能有三項 → x2 那項要消失：a − 3 = 0 → a = 3
先做 1-2 學過的「去括號＋合併」，整理完條件自己就浮出來。
例③【進階】A = a(x2+2x−1) + b(x2+3) + 4x − 5 是零次多項式，求這個零次多項式
展開整理：(a+b)x2 + (2a+4)x + (−a+3b−5)
「零次」→ a+b = 0 且 2a+4 = 0 → a = −2、b = 2
常數項 = −(−2)+3·2−5 = 3（≠0，符合零次多項式）
兩個「＝0」湊成聯立，解出 a、b 再回代常數。零次＝只剩非零常數。
例④【進階】A = (2a+b)x2 − 11x + (3a−b)、B = −x2 + (a−3b)x + c，若 A = B，比較 a、b、c 大小
A＝B → 同次項係數各自相等：
x2：2a+b = −1　；　x：a−3b = −11　；　常數：3a−b = c
解前兩條 → a = −2、b = 3；代入 → c = 3(−2)−3 = −9
−9 < −2 < 3 → c < a < b
「A=B」一句話就是三條等式。x 那條連 −11 的負號一起比對，最容易錯在符號。
例⑤【基礎・陷阱】(x+1)+(x+2)+⋯+(x+100)，x 項的係數和是多少？
共 100 個括號，每個貢獻一個 1x → 係數和 = 100
（1+2+⋯+100 = 5050 是常數項的和，題目沒問它）
x 項歸 x 項、常數歸常數，分開整理。5050 就是這題設好的陷阱選項。
例⑥【挑戰・圖形周長】把邊「平移」再算
凹口的直邊「平移」回外框（紅虛線）後：直的、橫的邊總長都跟外框一樣
只有凹口「一進一出」那兩段（各 5）是多出來的 → 周長 = 外框周長 + 2×5
所以外框相同的兩個圖，周長差 = 2×5 = 10
遇到樓梯形/凹形不用一段段硬加：先算外框 2×(長+寬)，再加「每個凹口深度 × 2」。
係數條件題兩步：① 整理成 □x²＋□x＋□（該去括號就去、該合併就合）② 條件翻譯成係數的等式再解。跳過整理直接猜，就會卡住。

自己做一遍，錯的訂正後一樣算過

先自己算，再對解答。做錯的填最下面表格。

觀念辨識（答錯可再選）

1. 下列哪組是同類項？
文字要完全一樣。3x 與 −7x 都是 x。
再看一次，選出正確的。
2. −(x − 3) 去括號等於？
每項變號：x→−x、−3→+3，得 −x+3。
再看一次，選出正確的。
3. 4a + 5 − a 合併後是？
a 類 4a−a=3a；常數 5 留著。
再看一次，選出正確的。
4. 42+2x 是幾次多項式？
42=16 是常數，式子＝16+2x，最高次是 x 的一次。次數只看文字的指數。
再看一次，選出正確的。
5. 多項式 −3+3x2 的項數是？
被加減分開的只有 −3 和 3x2 兩塊，項數 2。（係數的 3 不是一項）
再看一次，選出正確的。
6. 多項式 −x+x2+2 中，x 項的係數是？
先降冪排列：x2 − x + 2。x 項是 −x = −1x，係數是 −1——負號要跟著係數。

7. 流程圖追蹤：第一格問「42+2x 是一個二次多項式？」，是→上路（判斷 −x+x2+2 的 x 項係數是否為 −1：是→甲、否→乙）；否→下路（判斷 −3+3x2 的項數是否為 3：是→丙、否→丁）。最後到達？

多項式乘除 · 分配律

外面那個，要乘進去每一項

乘法的根本動作只有一個：分配律。先把「指數怎麼算」講清楚。

單項式乘除先備

同底數相乘，指數相加：xm · xn = xm+n（例：x·x2 = x3）

同底數相除，指數相減：xm ÷ xn = xm−n（x ≠ 0）

數字係數照一般乘除算，例如 2x · 3x2 = 6x3。

圖
高 a、底 (b+c) 的長方形＝兩塊 a·b + a·c
代數
a(b + c) = ab + ac
白話

括號外面那一個，要分別乘進括號裡的每一項，一項都不能漏。

a(b + c) = ab + ac
例：2x(3x − 4)
= 2x·3x − 2x·4 = 6x2 − 8x
2x 分別乘 3x 和 −4。x·x=x2。
常見錯誤：只乘第一項，寫成 6x2 − 4，漏了 2x 乘 −4。
多項式乘除 · 相乘

兩個括號：逐項乘，一項不漏

(a+b)(c+d) 就是前面每一項分別乘後面每一項，四塊全加起來。

(a+b)(c+d) = ac + ad + bc + bd
例：(x + 2)(x + 3)
= x2 + 3x + 2x + 6 = x2 + 5x + 6
四塊乘完，再合併同類項（3x、2x）。
其實 1-1 的乘法公式就是這個的特例：(x+3)(x+3) 是和的平方、(x+4)(x−4) 是平方差。認得長相就能跳過逐項乘。
常見錯誤：只乘「頭乘頭、尾乘尾」兩塊，漏掉中間交叉兩塊。四塊都要。
多項式乘除 · 除以單項式

除以單項式：每一項各除

最常考的除法，把每一項分別除。

(ab + ac) ÷ a = b + c　(a ≠ 0)
例：(6x2 + 4x) ÷ 2x　(x ≠ 0)
= 6x2÷2x + 4x÷2x = 3x + 2
每一項各除以 2x。6x2÷2x=3x（指數相減）、4x÷2x=2。因為除式是 2x，此計算須在 x≠0 時成立。
常見錯誤：只把第一項除、後面照抄。每一項都要除到。
多項式乘除 · 多項式÷多項式

除式有兩項以上：用直式長除法

除式含兩項（例如 x+2）時，像整數的長除法一樣，一階一階除。

首項除首項 → 回乘 → 相減 → 落下一項 → 再一輪
例（整除）：(x2 + 5x + 6) ÷ (x + 2)
① x2÷x = x（商第一項）；x·(x+2)=x2+2x
② 相減：(x2+5x)−(x2+2x)=3x，落下 +6 → 3x+6
③ 3x÷x = 3（商第二項）；3·(x+2)=3x+6；相減 = 0
商 = x + 3，餘 0
驗算：(x+2)(x+3)=x2+5x+6 ✓
寫成直式（跟紙本一樣的排版）：
x + 3 ┌────────────── x + 2 │ x² + 5x + 6 x² + 2x ────────── 3x + 6 3x + 6 ─────── 0
例（有餘式）：(x2 + 3x + 5) ÷ (x + 1)
商 x：x·(x+1)=x2+x；相減得 2x，落下 +5 → 2x+5
商 +2：2·(x+1)=2x+2；相減得 3
商 = x + 2，餘 3
缺項要補 0（佔位）：例如 x3 − 4x + 3 沒有 x2 項，要當成 x3 + 0x2 − 4x + 3 再除，不然位子會對錯。
