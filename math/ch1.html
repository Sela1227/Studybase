這是國二上的第一章，也是整條代數的第一塊磚。這裡熟練後，第3章因式分解、第4章一元二次方程式都會更好懂——它們反過來會用到這裡的公式。

前置快篩：乘方、正負號、分配律、單項式乘法、同類項合併預計 40 分鐘／節當「從頭學」設計，不預設你記得
乘法公式 · 和的平方

(a+b)2 到底等於什麼？

先講一個超常見的錯：很多人以為 (a+b)2 = a2+b2。這是錯的。在看公式前，先確認兩個基礎動作。

開始前先記住兩件事

① 平方的意思：(a+b)2 是 (a+b)(a+b)，不是把括號裡各自平方。

② 兩個括號相乘：第一個括號的每一項，都要分別乘第二個括號的每一項：

(a+b)(a+b) = a·a + a·b + b·a + b·b
公式裡的 a、b 代表「一整項」：不一定是單一字母，可以是一個數、一個單項式、或整個式子。例如 (2x−5)2 要把 2x 整體當成 a。
圖
邊長 (a+b) 的正方形，切成四塊：a2、ab、ab、b2
圖以正數示意；公式對正數、負數與 0 都成立
代數
(a+b)2 = (a+b)(a+b) = a2 + ab + ab + b2 = a2 + 2ab + b2
白話

平方一個「和」，中間會多出兩塊 ab（合起來 2ab）。漏掉這個 2ab，就是最常見的錯。

(a+b)2 = a2 + 2ab + b2
例：展開 (x+3)2
= x2 + 2·(x)·(3) + 32 = x2 + 6x + 9
a=x、b=3。中間 6x 就是 2ab=2·x·3。
常見錯誤：把 (x+3)2 寫成 x2+9，漏掉中間 6x。看到平方，先問「中間那項呢？」
乘法公式 · 差的平方

(a−b)2 只差一個符號

跟和的平方幾乎一樣，只是中間那項變號。看圖就懂為什麼是 −2ab。

圖
從 a2 扣掉兩條 ab，右下角的 b2 被扣了兩次，要補回來：a2 − ab − ab + b2 = (a−b)2
圖以正數（且 a > b）示意；公式對正數、負數與 0 都成立
代數
(a−b)2 = (a−b)(a−b) = a2 − ab − ab + b2 = a2 − 2ab + b2
白話

跟和的平方長得一樣，只有中間那項變減號。最後一項 b2 還是加的（負負得正）。

(a−b)2 = a2 − 2ab + b2
例：展開 (2x−5)2
= (2x)2 − 2·(2x)·(5) + 52 = 4x2 − 20x + 25
a=2x，所以 a2=(2x)2=4x2，係數 2 也要平方。
常見錯誤：(2x−5)2 第一項寫成 2x2。要 (2x)2=4x2，把 2x 整體當 a。
乘法公式 · 平方差

同兩項、一加一減，中間才會抵消

同樣的兩項，一個相加、一個相減時，相乘的中間兩項才會互相抵消，只剩兩個平方相減。

圖 · 切割重排
左：邊長 a 的正方形挖掉角落 b2，把下面那塊（綠）切下來、轉 90° 移到右邊；右：重排成長 (a+b)、寬 (a−b) 的長方形。所以 a2−b2 = (a+b)(a−b)。
圖以正數（且 a > b）示意；公式對正數、負數與 0 都成立
代數
(a+b)(a−b) = a2 − ab + ab − b2 = a2 − b2 （中間 −ab+ab 抵消）
白話

只有「同兩項、一加一減」中間才抵消。像 (x+5)(x−3) 這種兩項不同的，不會抵消，不能用平方差。

(a+b)(a−b) = a2 − b2
例：展開 (x+4)(x−4)
= x2 − 42 = x2 − 16
符合「同兩項、一加一減」，直接套平方差。
用之前先確認：兩括號要「同兩項、只差 +/−」。(x+4)(x+4) 是和的平方；(x+4)(x−3) 兩者都不是。
乘法公式 · 速算（數字版）

公式換上數字外衣：考卷上的速算題

這種題型在你的考卷上出現過。它們考的不是新東西——就是這三個公式，只是把 a、b 換成數字。訣竅只有一個：把數字改寫成「好算的基準 ± 一點點」。

選基準：挑最近的整十、整百，或兩數的正中間
例①【基礎】1022
= (100 + 2)2 = 1002 + 2·100·2 + 22 = 10000 + 400 + 4 = 10404
基準選 100。中間 2ab=400 一樣不能漏。
例②【核心必會】帶分數平方：(40¾)2 = 402 + a，求 a
(40 + ¾)2 = 402 + 2·40·¾ + (¾)2 = 402 + 60 + 9/16
a = 60 916
這題最容易只答 9/16——那就是漏了中間 2ab = 2·40·¾ = 60。帶分數平方跟 (a+b)² 一模一樣，中間那項照樣在。
例③【進階】選基準：3002 × 2998 − 29972 的十位數字
3002×2998 = (3000+2)(3000−2) = 30002 − 22 = 8,999,996
29972 = (3000−3)2 = 9,000,000 − 18,000 + 9 = 8,982,009
相減 = 17,987 → 十位數字 = 8
基準不只一種。本例選 3000（兩數正中間），「一加一減」的平方差外觀最明顯；連 2997² 也能再用一次差的平方。
另一種一樣正確的解法（以 2997 為基準）：3002=2997+5、2998=2997+1 → (2997+5)(2997+1) − 2997² = 2997² + 6·2997 + 5 − 2997² = 17,982 + 5 = 17,987。抓「共同基準」的想法是對的——展開後把 2997² 消掉，剩下的整理好就是答案。兩條路都通，挑你看得順的。
例④【挑戰・兩層公式】在數字裡認出公式：170×168/169 + 1/169 + 2×13×17 + 289
第一步・分數合併：170×168 = (169+1)(169−1) = 1692 − 1
(1692 − 1)/169 + 1/169 = (1692 − 1 + 1)/169 = 1692/169 = 169
第二步・認出平方：169 = 132、289 = 172，剩下的排成三塊——
169 ＋ 2×13×17 ＋ 289
＝ 132（a2）　＋　2·13·17（2ab）　＋　172（b2）
= (13 + 17)2 = 302 = 900
兩層公式：分數那邊是平方差；後面是「a²+2ab+b² 的長相」。背 13²=169、17²=289 這些常見平方數會快很多。
速算題三步：① 選基準（整十百／兩數中點）② 改寫成 (基準±小)，認出是哪個公式 ③ 套公式，中間項不漏。認不出公式就會退回硬算——又慢又容易錯，這正是這種題想考的。

先分清楚，再自己做

多項式 · 判讀

先把名字認清楚，再學一套固定的判讀流程

項、係數、次數是這章所有題目的語言；判讀四步驟則是考卷上不會錯的 SOP。

多項式 = 一個或多個「單項式」相加減，且文字的指數都是 0、1、2、3…（不能是負數或分數）

例如 3x2 − 5x + 2 是多項式；單獨一項 3x2 也算多項式。但 x−1（＝1/x）、√x 這種指數是負數或分數的，不是多項式。

詞意思在 3x2 − 5x + 2 裡
項被加減分開的每一塊3x2、−5x、2 共三項
係數項前面的數字3、−5
常數項沒有文字的項2
次數怎麼算：一個單項式的次數是「各文字指數的總和」——例如 3a2b 是 2+1=3 次。多項式的次數，是各項中最高的那個次數（3x2−5x+2 是二次）。目前只有一個 x 的式子，一項的次數就等於 x 的指數。
數字的平方不是次數：42+2x 裡的 42 只是 16（常數），所以 42+2x = 16+2x 是一次多項式，不是二次。次數只看文字的指數。
判讀四步驟：① 先算掉純數字（4²→16）② 依次數由高到低排列 ③ 用加減號切項（負號跟著後面那項）④ 再判斷項數、次數、指定項係數
用四步驟整理三個式子（考卷流程圖裡的三位主角）
原式降冪整理項數次數x2 係數x 係數常數項
42+2x2x+16210216
−x+x2+2x2−x+2321−12
−3+3x23x2−32230−3
三個易錯點都在表裡：省略的係數（−x 的係數是 −1）、缺項的係數是 0（3x²−3 沒有 x 項 → x 係數 0）、數字平方只是常數。
零次多項式 vs 零多項式（別搞混）：「3」是零次多項式——只有一個不為 0 的常數項。「0」是零多項式——所有係數（含常數）都是 0，通常不定義它的次數。
同類項 = 文字部分「完全一樣」的項

3x 和 −5x 是同類（都是 x）；3x 和 3x2 不是同類。這個判斷是下一課的關鍵。

多項式 · 合併與指定項追蹤

同類才能合；題目問哪一類，就只追蹤哪一類

合併同類項是基本功；「指定項追蹤」是它的考試版。

白話

3 個 x 加 2 個 x，是 5 個 x——像 3 顆蘋果加 2 顆蘋果。但蘋果不能跟橘子合：x 和 x2 不同類，不能加。

代數
3x + 2x = (3+2)x = 5x　係數相加，x 不動
3x + 2x2 不同類，不能合
分類
同類（可合）不同類（不可合）
7a 與 −2a7a 與 7b
x2 與 4x2x2 與 x
5 與 −3（常數）5 與 5x
例：合併 4x + 3 − x + 5
= (4x − x) + (3 + 5) = 3x + 8
同類擺一起：x 類合成 3x，常數合成 8。不同類的分開寫。
常見錯誤：把 3x + 8 再算成 11x。x 類和常數不同類，答案就是 3x + 8。
指定項追蹤：題目只問哪一類，就只把那一類挑出來加，其他的看都不用看
例：(2x+1) + (3x+2) + (4x+3) 中，x 項的係數和是多少？
只追蹤 x 項：2 + 3 + 4 = 9
（常數 1+2+3=6 題目沒問，不用算）
重點是「追蹤指定的那一類」——不是把整個式子合併完才找答案，那樣又慢又容易抄錯。
多項式 · 加減、去括號與代換

減號去括號全變號；代換題先化簡外殼

前半是這章最容易掉分的地方；後半是考卷上的代換題型，先教再考。

− ( a − b + c ) = − a + b − c

括號前是 加號：直接拿掉。括號前是 減號：裡面每一項都變號——不是只有第一項。

例：(3x2 + 2x − 1) − (x2 − 4x + 5)
= 3x2 + 2x − 1 − x2 + 4x − 5
= 2x2 + 6x − 6
紅色是重點：三項全變號，再合併。
最常見的錯：減號只把第一項變號，後面照抄。去減號括號時，每一項都盯著變號。
代換題口訣：先化簡「外殼」（A、B 的組合），再代入「內容」
例：A = 2x−1、B = x+3，化簡 (A+B)/2 − (A−2B)/3
先不代入，通分：= 3(A+B)/6 − 2(A−2B)/6 = (3A+3B−2A+4B)/6
= (A + 7B)/6　（外殼化到最簡）
再代入：= ((2x−1) + 7(x+3))/6 = (2x−1+7x+21)/6 = (9x+20)/6
先併外殼只要處理 A、B 兩個符號；一開始就代入，每一步都拖著長長的式子。特別注意：減的是「整個分式」，通分後 −(A−2B) 裡每一項都要變號：−A+2B。
多項式 · 係數條件與相等

條件都藏在「係數」裡

這型題在你的考卷出現最多次。心法兩步：① 先展開、合併同類項，依次數由高到低排列成 ⋯＋□x³＋□x²＋□x＋□　② 把條件翻譯成各次項係數的等式。

題目條件正確翻譯
是「一次」多項式二次以上係數全為 0，且 x 係數 ≠ 0
是「零次」多項式所有含 x 的項係數為 0，且常數項 ≠ 0
是「零多項式」所有係數（包括常數項）都為 0
A ＝ B降冪排列、缺項補 0 後，同次項係數各自相等
結果有 n 個相異項完全整理後，恰有 n 個「係數不為 0」的項
缺項補 0：x2 + 3 要看成 x2 + 0x + 3——沒有的項，係數就是 0。這個習慣在 1-3 的長除法也會用到。
例①【核心必會】(m−3)x2 + (m+n−4)x + 7 是 x 的一次多項式，且 x 項係數為 3，求 2m+3n
「一次」→ x2 係數＝0：m − 3 = 0 → m = 3
「x 係數為 3」→ m + n − 4 = 3 → 3 + n − 4 = 3 → n = 4
2m + 3n = 6 + 12 = 18
兩個條件、兩條式子、逐一解出。最容易的失誤是只用一個條件就急著代入。
例②【核心必會】(x3+2x2−1) − (5+bx2−x) 的結果只有三個相異的項，求 b
去括號整理：x3 + (2−b)x2 + x − 6　（目前四種項）
只能有三項 → x2 那項要消失：2 − b = 0 → b = 2
先做去括號＋合併，整理完條件自己就浮出來。
例③【進階】A = a(x2+x−2) + b(x2+1) + 3x + 4 是零次多項式，求它的值
展開整理：(a+b)x2 + (a+3)x + (−2a+b+4)
「零次」→ a+b = 0 且 a+3 = 0 → a = −3、b = 3
常數項 = 6+3+4 = 13（≠0，符合零次多項式）
兩個「＝0」湊成聯立；如果連常數也是 0，那就是「零多項式」，不是零次。
例④【進階】A = (m+n)x2 − 4x + (2m−n)、B = 5x2 + (m−2n)x + k，若 A = B，比較 m、n、k
次數A 的係數B 的係數建立等式
x2m+n5m+n = 5
x−4m−2nm−2n = −4
常數2m−nk2m−n = k
解前兩條 → m = 2、n = 3；代入 → k = 4−3 = 1
1 < 2 < 3 → k < m < n
A=B 一句話＝一張係數對照表。x 那列連 −4 的負號一起放進去，符號就不會丟。
係數條件題兩步：① 展開合併、降冪排列（缺項補 0）② 條件翻譯成係數等式再解。跳過整理直接猜，就會卡住。
多項式 · 圖形應用

把圖形翻譯成多項式：周長、面積

由易到難三種：長方形周長 → 十字道路面積 → 凹槽周長。都是「先寫公式、再代入、再合併」。

型①【基礎】長 7x+4、寬 3x+5 的長方形，周長是多少？
先寫公式：P = 2(長 + 寬)
代入：= 2[(7x+4) + (3x+5)] = 2(10x + 9) = 20x + 18
先寫 P=2(長+寬) 再代入合併——直接硬加四邊也可以，但容易漏。
型②【核心必會】長 a、寬 b 的土地，開一條寬 x 的十字型道路，剩餘面積是多少？
法一（扣道路）：橫路 ax、直路 bx，中間 x2 被扣了兩次要補回 → 道路面積 = ax + bx − x2
剩餘 = ab − ax − bx + x2
法二（平移拼合）：把道路移到邊上，剩下的拼成一塊 (a−x)(b−x) 的長方形
ab − ax − bx + x2 = (a − x)(b − x)　展開檢查，兩法答案相同
兩條路交會處只有一塊 x²，直接 ax+bx 會重複扣一次——這是本題的核心陷阱。兩法互相驗算最保險。（圖中假設 a、b、x ＞ 0 且 x ＜ a、x ＜ b——道路不能比土地還寬。）
型③【挑戰】凹槽周長：把邊「平移」再算
適用條件：外框是矩形、往內挖一個深度 d 的矩形凹槽
凹槽的直邊平移回外框後，直、橫邊總長跟外框一樣；只多出「一進一出」兩段（各 d）
周長 = 外框周長 + 2d（例：d = 4 → 多 8）
這個「+2d」只對矩形凹槽成立，不能泛化成所有不規則圖形；形狀複雜時，還是回到平移逐邊對照。

多項式乘除 · 分配律
這一節內容較多，建議分 2～3 次完成（每次約 40 分鐘）：第一回「基本乘除與長除法」、第二回「代值法與除法原理」、第三回「公式進階應用與錯題再測」。

外面那個，要乘進去每一項

乘法的根本動作只有一個：分配律。先把「指數怎麼算」講清楚。

單項式乘除先備

同底數相乘，指數相加：xm · xn = xm+n（例：x·x2 = x3）

同底數相除，指數相減：xm ÷ xn = xm−n（x ≠ 0）

數字係數照一般乘除算，例如 2x · 3x2 = 6x3。

圖
高 a、底 (b+c) 的長方形＝兩塊 a·b + a·c
代數
a(b + c) = ab + ac
白話

括號外面那一個，要分別乘進括號裡的每一項，一項都不能漏。

a(b + c) = ab + ac
例：2x(3x − 4)
= 2x·3x − 2x·4 = 6x2 − 8x
2x 分別乘 3x 和 −4。x·x=x2。
常見錯誤：只乘第一項，寫成 6x2 − 4，漏了 2x 乘 −4。
多項式乘除 · 相乘

兩個括號：逐項乘，一項不漏

(a+b)(c+d) 就是前面每一項分別乘後面每一項，四塊全加起來。

(a+b)(c+d) = ac + ad + bc + bd
例：(x + 2)(x + 3)
= x2 + 3x + 2x + 6 = x2 + 5x + 6
四塊乘完，再合併同類項（3x、2x）。
其實 1-1 的乘法公式就是這個的特例：(x+3)(x+3) 是和的平方、(x+4)(x−4) 是平方差。認得長相就能跳過逐項乘。
常見錯誤：只乘「頭乘頭、尾乘尾」兩塊，漏掉中間交叉兩塊。四塊都要。
多項式乘除 · 除以單項式

除以單項式：每一項各除

最常考的除法，把每一項分別除。

(ab + ac) ÷ a = b + c　(a ≠ 0)
例：(6x2 + 4x) ÷ 2x　(x ≠ 0)
= 6x2÷2x + 4x÷2x = 3x + 2
每一項各除以 2x。6x2÷2x=3x（指數相減）、4x÷2x=2。因為除式是 2x，此計算須在 x≠0 時成立。
常見錯誤：只把第一項除、後面照抄。每一項都要除到。
多項式乘除 · 多項式÷多項式

除式有兩項以上：用直式長除法

除式含兩項（例如 x+2）時，像整數的長除法一樣，一階一階除。

首項除首項 → 回乘 → 相減 → 落下一項 → 再一輪
例（整除）：(x2 + 5x + 6) ÷ (x + 2)
① x2÷x = x（商第一項）；x·(x+2)=x2+2x
② 相減：(x2+5x)−(x2+2x)=3x，落下 +6 → 3x+6
③ 3x÷x = 3（商第二項）；3·(x+2)=3x+6；相減 = 0
商 = x + 3，餘 0
驗算：(x+2)(x+3)=x2+5x+6 ✓
寫成直式（跟紙本一樣的排版）：
x + 3 ┌────────────── x + 2 │ x² + 5x + 6 x² + 2x ────────── 3x + 6 3x + 6 ─────── 0
例（有餘式）：(x2 + 3x + 5) ÷ (x + 1)
商 x：x·(x+1)=x2+x；相減得 2x，落下 +5 → 2x+5
商 +2：2·(x+1)=2x+2；相減得 3
商 = x + 2，餘 3
缺項要補 0（佔位）：例如 x3 − 4x + 3 沒有 x2 項，要當成 x3 + 0x2 − 4x + 3 再除，不然位子會對錯。
多項式乘除 · 代值法與除法原理（實戰）

不用展開完：挑一個好算的數代進去

這幾種題型在你的考卷出現過。核心只有一句：恆等式對「任何 x」都成立，所以可以挑一個最好算的 x 代進去。

使用前提：「代值」與「比係數」都只在恆等式（左右是同一個多項式、對所有 x 都成立）時才能用。若等式只對某個未知的 x 成立，就不能任意另代一個數。
題目要的代什麼為什麼
展開後「係數總和」（含常數項）x = 1每一項的 x 都變 1，剩下的就是係數相加
展開後「常數項」x = 0含 x 的項全變 0
式子含 (x−1)、(x−2)…x = 1、x = 2…讓那個括號變 0，一堆項直接消失
例①【核心必會】(3x−2)(2x2+x−4) 展開後，係數的總和是多少？
不用真的展開！代 x = 1：(3−2)(2+1−4) = (1)(−1) = −1
展開後每一項是「係數 × x 的次方」，代 x=1 後就是所有係數（含常數項）相加。乘出來再加，又慢又容易錯。
例②【核心必會】設 2x2−3x+5 = a(x−1)2 + b(x−1) + c 為恆等式（對所有 x 成立），求 a+b+c
右邊代 x = 2 時剛好是 a+b+c（每個括號都變 1）
左邊代 x = 2：8 − 6 + 5 = 7 → a+b+c = 7
也可以展開比較係數（a=2、b=1、c=4，一樣是 7），但看出「代 x=2」就是一行的事。
題目外觀優先策略
左右都是展開好的多項式比較係數
出現 (x−h)、(x−h)2先試代 x = h（讓它變 0）
要求 a+b+c，右邊是 a(x−h)2+b(x−h)+c代 x = h+1（每個括號變 1）
只要求常數或少數係數試 x = 0、1、−1
兩招都要會：比係數是「全都要」的萬用解；代特殊值是「只要其中幾個」的快捷鍵。先看題目要什麼，再選招。
例③【進階・課本以外】餘式定理：f(x) 除以 (x−k)，餘式 = f(k)
原因：f(x) = (x−k)×商 + 餘。代 x = k，前面整塊變 0 → f(k) = 餘
例：x2+3x+1 除以 (x−2) 的餘式 = f(2) = 4+6+1 = 11（不用長除法）
這在課本進度之外，但你的考卷考過。它就是「代值法＋除法原理」的合體。
除式要代入的值
x − 3x = 3
x + 2x = −2（x+2 = x−(−2)）
2x − 1（進階）x = 1/2（讓除式 = 0 的值）
口訣：代「讓除式變 0」的那個數。除以 x+1 是代 −1，不是 +1——這裡最容易錯。
例④【進階】除法原理：2x2+ax+3 除以 (x−1)，商是 2x+5、餘 8，求 a
寫回乘法：2x2+ax+3 = (x−1)(2x+5) + 8
右邊展開 = 2x2+3x−5+8 = 2x2+3x+3 → 比較 x 係數：a = 3
「被除式 = 除式 × 商 + 餘」是除法的身分證。已知商餘求係數，就把它寫回乘法再比較係數（1-2 學過的方法在這裡合體）。
例⑤【進階】整體代換：已知 x2+3x = 5，求 2x2+6x+9
2x2+6x+9 = 2(x2+3x) + 9 = 2·5 + 9 = 19
不用解出 x！把 x2+3x 當「一整塊」提出來換成 5。找不到怎麼提時，也可以用除法：拿目標式除以已知式，商和餘會告訴你怎麼拆。
代值法三問：① 這是恆等式嗎（對任何 x 成立）？② 題目要的是什麼組合？③ 代哪個數能讓式子變成那個組合？三問答完，多數題一行就結束。
多項式乘除 · 公式的進階應用（實戰）

乘法公式的變形題：對稱式、因數、分式

這幾型也來自你的考卷——公式不只拿來展開，還能「反著用、變形用」。

例①【核心必會】對稱式：a + 1/a = 5（a ≠ 0），求 a2 + 1/a2
把已知平方：(a + 1/a)2 = a2 + 2·a·(1/a) + 1/a2 = a2 + 2 + 1/a2
25 = a2 + 1/a2 + 2 → a2 + 1/a2 = 23
中間項 2·a·(1/a) 永遠等於 2——這就是這型題的開關：x²+y² = (x+y)² − 2xy。
例②【核心必會】用平方差拆數字：將 3599 因式分解，判斷是否為質數，並求它的正因數總和
3599 = 3600 − 1 = 602 − 12 = (60+1)(60−1) = 61 × 59
59、61 都是質數 → 3599 不是質數；正因數恰為 1、59、61、3599，總和 = 3720
看到「接近完全平方數」的數，先試平方差拆它。拆開後因數、因數和都是送分。
例③【進階】奇偶分析：P、Q 是大於 1 的正整數，Q2 − P2 = 16，求 P+Q
(Q+P)(Q−P) = 16，且 Q+P 與 Q−P 奇偶性相同（兩者相加是偶數 2Q）
16 拆成同偶：8 × 2 → Q+P=8、Q−P=2 → Q=5、P=3 → P+Q = 8
16×1、4×4 為何不行？16×1 一偶一奇 ✗；4×4 → Q−P=4、Q+P=4 → P=0 不合「大於1」✗。列表逐組檢查就不會漏。
分式四步驟：① 先寫限制（分母 ≠ 0 的所有值）② 分母因式分解 ③ 通分／約分 ④ 答案旁保留原限制
例④【挑戰・課本以外】分式化簡：2x/(x2−9) − 1/(x−3)
① 限制：x2−9≠0 且 x−3≠0 → x ≠ ±3（兩個分母都要看）
② 分母分解：x2−9 = (x+3)(x−3) → ③ 通分：= [2x − (x+3)] / (x2−9)
= (x − 3) / [(x+3)(x−3)] = 1/(x+3)　（x ≠ ±3）
兩步都靠公式：分母用平方差分解找公分母；分子相減後再檢查能不能跟分母約分——差一步就選到錯的選項。減整個分式時每項都要變號（1-2 的老朋友）。
例⑤【核心必會】梯形面積：上底 3x+1、下底 5x+3、高 x+2
先寫公式：面積 = (上底+下底)×高 ÷ 2
= ½(8x+4)(x+2) = (4x+2)(x+2) = 4x2 + 10x + 4
½ 先跟 (8x+4) 約分再展開，數字小很多。幾何題永遠「公式先行、再代入、再展開」。
例⑥【進階】連鎖消去：(1−1/22)(1−1/32)(1−1/42)
每一項用平方差拆：1 − 1/n2 = (1−1/n)(1+1/n) = (n−1)/n × (n+1)/n
= (1/2 · 3/2)(2/3 · 4/3)(3/4 · 5/4)，分成兩串：(1/2·2/3·3/4)×(3/2·4/3·5/4)
中間互相消掉，只剩頭尾：= (1/4) × (5/2) = 5/8
三層結構：平方差 → 拆成兩串 → 連鎖消去。項數多的時候（例如乘到 1−1/20²）威力才顯出來——見再測。
大數與長串的共同口訣：看到巨大數字、超長連乘，先別代、先別乘——先找能約掉、能合成公式的結構。符號整理完，常常只剩一行。

觀念辨識（答錯可再選）

1. 3(x + 4) 等於？
3 要乘進每一項：3x + 12。
再看一次，選出正確的。
2. x · x2 等於？
同底數相乘指數相加：x1·x2=x3。
再看一次，選出正確的。
3. (x2+5x+6)÷(x+2) 的商是？
長除法：商 x+3，餘 0。驗算 (x+2)(x+3)=x²+5x+6。
再看一次，選出正確的。

基本計算

① 展開 3x(2x − 5)
= 6x2 − 15x
② 展開 (x + 5)(x + 2)
= x2 + 7x + 10
③ (8x2 − 6x) ÷ 2x　(x≠0)
= 4x − 3
④ (x2 + 7x + 12) ÷ (x + 3)（長除法）
商 = x + 4，餘 0
x·(x+3)=x²+3x，減得 4x+12；4·(x+3)=4x+12，減得 0。
⑤ (x2 + 3x + 5) ÷ (x + 1)（有餘式）
商 = x + 2，餘 3
x·(x+1)=x²+x，減得 2x+5；2·(x+1)=2x+2，減得 3（次數比除式低，停）。
⑥ (x3 − 4x + 3) ÷ (x − 1)（缺項補 0）
先寫成 x3 + 0x2 − 4x + 3；商 = x2 + x − 3，餘 0
缺 x² 項要補 0x² 佔位，直式的位置才對得齊。

錯題再測（考卷原題——先自己完整作答，再開解答；標【進階】者選做，不列入基本過關）：

再測① (5x−1)(−4x2−2x+6) 展開後，係數的總和
代 x=1：(5−1)(−4−2+6) = 4×0 = 0
係數總和（含常數項）= 代 x=1，不用展開。
再測② 梯形的兩平行底長分別為 AE=2x+3、CF=6x−1，高為 AB=x+7，求梯形面積
½[(2x+3)+(6x−1)](x+7) = (4x+1)(x+7) = 4x2+29x+7
再測③ ax2+bx+6 除以 x−1 餘 8、除以 x+1 餘 12，求 a、b
f(1)=a+b+6=8、f(−1)=a−b+6=12 → a=4、b=−2
餘式定理：除以 x+1 是代 x=−1。
再測④【進階】P、Q 為大於 1 的正整數，P2=8x+1、Q2=8x+25，求 P+Q
Q2−P2=24 → (Q+P)(Q−P)=24，取同奇偶的配對逐組檢查：12×2 → Q=7、P=5 ✓；6×4 → Q=5、P=1，不合 P＞1，捨去 → P+Q=12
固定流程：列因數配對 → 留同奇偶 → 解出 P、Q → 回頭檢查「正整數、＞1」。找到一組就停，會漏掉該捨去的檢查。
再測⑤ 2x2+ax−2 除以 cx−1 的商為 −2x+b、餘 2，求 2a+b+c
2x2+ax−2 = (cx−1)(−2x+b)+2 → 比較係數：c=−1、b=4、a=−2 → 2a+b+c = −1
再測⑥ 已知 x2+2x=3，求 5x2+10x+21（用小安與亮宇兩種除法策略）
小安：÷(x2+2x) 商 5 餘 21 → 5·3+21 = 36；亮宇：÷(x2+2x−3) 商 5 餘 36，而 x2+2x−3=0 → 36
兩條路答案相同；亮宇的除式剛好等於 0，值就是餘式。
再測⑦ 化簡 2x/(x2−4) − 1/(x−2)（原題寫 x≠2）
= [2x−(x+2)]/(x2−4) = (x−2)/[(x+2)(x−2)] = 1/(x+2)
分子減完要再跟分母約分。勘誤：原題只寫 x≠2，但分母 x²−4 在 x=−2 也是 0，完整限制應為 x ≠ ±2——照四步驟自己把限制寫全。
再測⑧【進階】a=8051=902−72，關於 a 的正確敘述？（因數角度）
a = (90+7)(90−7) = 97×83 → 正因數 1、83、97、8051，總和 = 8232
再測⑨ a + 1/a = 6（a ≠ 0），求 a2 + 1/a2
= 62 − 2 = 34
再測⑩ x3+ax+2 = (x−1)2(x+b) 為恆等式，求 ab
右邊展開 = x3+(b−2)x2+(1−2b)x+b → b−2=0 → b=2；a=1−2b=−3 → ab = −6
x² 係數為 0（左邊缺項）是解題入口。
再測⑪【進階】E(p,q) 在直線 x+y=1 上，且 p ≠ q。F( p/(p²−q²), q/(p²−q²) )，F 一定在哪條直線上？
F 的 x−y = (p−q)/(p²−q²) = 1/(p+q) = 1/1 = 1 → x−y=1
再測⑫【進階】a=2025、b=−2024，求 (1/a + 1/b) × 2ab/(a²+2ab+b²)
= (a+b)/ab × 2ab/(a+b)2 = 2/(a+b) = 2/1 = 2
再測⑬ 3x2−4x+6 = a(x−1)2+b(x−1)+c 為恆等式，求 a+b+c
代 x=2：12−8+6 = 10
右邊代 x=2 剛好是 a+b+c——跟例②同一招。
再測⑭【進階】(1−1/102)(1−1/112)⋯(1−1/202) 之值
每項拆 (n−1)/n × (n+1)/n → 兩串連鎖消去 = (9/20) × (21/10) = 189/200
跟例⑥同一個三層結構，只是串比較長：左串剩 9/20、右串剩 21/10。
