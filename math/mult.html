乘法公式 · 和的平方

(a+b)2 到底等於什麼？

先講一個超常見的錯：很多人以為 (a+b)2 = a2+b2。這是錯的。我們用三種方式看它為什麼錯、正確又是什麼。

圖
邊長 (a+b) 的正方形，切成四塊：a2、ab、ab、b2
代數
(a+b)2 = (a+b)(a+b) = a2 + ab + ab + b2 = a2 + 2ab + b2
兩個括號逐項相乘，中間 ab 出現兩次
白話

平方一個「和」，不是各自平方加起來——中間會多出兩塊 ab（合起來 2ab）。漏掉這個 2ab，就是最常見的錯。

(a+b)2 = a2 + 2ab + b2
例：展開 (x+3)2
= x2 + 2·(x)·(3) + 32 = x2 + 6x + 9
a=x、b=3。中間 6x 就是 2ab=2·x·3，不會憑空消失。
常見錯誤：把 (x+3)2 寫成 x2+9，漏掉中間 6x。看到平方，先問「中間那項呢？」
乘法公式 · 差的平方

(a−b)2 只差一個符號

跟和的平方幾乎一樣，只是中間那項變號。

圖
從邊長 a 的大正方形扣掉兩條 ab、再補回多扣的一塊 b2
代數
(a−b)2 = (a−b)(a−b) = a2 − ab − ab + b2 = a2 − 2ab + b2
白話

跟和的平方長得一樣，只有中間那項變減號。最後一項 b2 還是加的（負負得正）。

(a−b)2 = a2 − 2ab + b2
例：展開 (2x−5)2
= (2x)2 − 2·(2x)·(5) + 52 = 4x2 − 20x + 25
a=2x，所以 a2=(2x)2=4x2，係數 2 也要平方。
常見錯誤：(2x−5)2 第一項寫成 2x2。要 (2x)2=4x2。
乘法公式 · 平方差

(a+b)(a−b) 中間剛好消掉

一加一減相乘，中間兩項互相抵消，只剩兩個平方相減。

圖
邊長 a 的正方形，挖掉角落那塊 b2，剩下的 L 形面積 = a2 − b2，重排後正好是 (a+b)(a−b)
代數
(a+b)(a−b) = a2 − ab + ab − b2 = a2 − b2 （中間 −ab+ab 抵消）
白話

兩個括號「同兩項、一加一減」，中間剛好消掉，只剩前平方減後平方。認得這長相，計算快很多。

(a+b)(a−b) = a2 − b2
例：展開 (x+4)(x−4)
= x2 − 42 = x2 − 16
符合「同兩項、一加一減」，直接套平方差，不用乘四項。
用之前先確認：兩括號要「同兩項、只差 +/−」。(x+4)(x+4) 不行，那是和的平方。

自己做一遍，錯的要分類

題目和解答分開。先自己算，卡住或算完再看解答。做錯的用最下面的表格勾「錯在哪一種」。

觀念辨識（判斷對錯，先過這關）

1. (a+b)2 = a2 + b2，對嗎？
正確是 a2+2ab+b2。平方一個和，中間一定有 2ab。
2. (x−7)2 的中間項是？
差的平方中間帶減號：−2·x·7 = −14x。
3. 哪一個可以直接套「平方差」？
平方差要「同兩項、一加一減」。只有 (x+5)(x−5)，結果 x2−25。
4. (3x+1)2 的第一項是？
a=3x，a2=9x2。係數 3 也要平方。

基本計算（自己展開，再對解答）

① 展開 (x+6)2
= x2 + 12x + 36
中間 2ab=12x 不能漏。
② 展開 (2a−3)2
= 4a2 − 12a + 9
(2a)2=4a2，係數一起平方；中間帶減號。
③ 展開 (y+8)(y−8)
= y2 − 64
認出平方差，前平方減後平方。
④ 展開 (5−x)(5+x)
= 25 − x2
順序反過來也一樣，抓「同兩項、一加一減」。

多項式加減 · 名詞

先把名字認清楚

不用背定義，先看懂這幾個詞在講什麼，後面才知道「同類」是什麼意思。

多項式就是好幾個「項」用加減連起來，例如 3x2 − 5x + 2。

詞意思在 3x2 − 5x + 2 裡
項被加減分開的每一塊3x2、−5x、2 共三項
係數項前面的數字3、−5
次數文字的指數3x2 是二次
常數項沒有文字的項2
同類項 = 文字部分「完全一樣」的項

例如 3x 和 −5x 是同類（都是 x）；但 3x 和 3x2 不是同類（一個一次、一個二次）。這個判斷是下一課的關鍵。

先記住：只有同類項能相加減。這是後面所有多項式運算的第一個關卡。
多項式加減 · 合併同類項

同類才能合，係數相加、文字不變

合併同類項是多項式最基本的動作。用三種方式看它。

白話

3 個 x 加 2 個 x，是 5 個 x——就像 3 顆蘋果加 2 顆蘋果是 5 顆。但蘋果不能跟橘子合起來：x 和 x2 不同類，不能加。

代數
3x + 2x = (3+2)x = 5x　係數相加，x 不動
3x + 2x2 不同類，不能合，只能原樣留著
分類
同類（可合）不同類（不可合）
7a 與 −2a7a 與 7b
x2 與 4x2x2 與 x
5 與 −3（常數）5 與 5x
例：合併 4x + 3 − x + 5
= (4x − x) + (3 + 5) = 3x + 8
先把同類的擺一起：x 類（4x、−x）合成 3x，常數（3、5）合成 8。不同類的分開寫。
常見錯誤：把 3x + 8 再硬算成 11x。x 類和常數不同類，不能再合，答案就是 3x + 8。
多項式加減 · 去括號

減號去括號，裡面全變號

這是整個第1章最容易掉分的地方，慢慢看。

− ( a − b + c ) = − a + b − c

括號前面是 加號：直接把括號拿掉，裡面不變。
括號前面是 減號：括號拿掉時，裡面每一項都要變號——不是只有第一項。

例：(3x2 + 2x − 1) − (x2 − 4x + 5)
= 3x2 + 2x − 1 − x2 + 4x − 5
= (3x2 − x2) + (2x + 4x) + (−1 − 5)
= 2x2 + 6x − 6
紅色那段是重點：第二個括號前面是減號，所以 x2→−x2、−4x→+4x、+5→−5，三項全變號。變完再合併同類項。
最常見的錯：減號只把第一項變號，後面照抄，寫成 …− x2 − 4x + 5。這一個錯就會讓整題垮掉。去減號括號時，每一項都盯著變號。
練習與訂正

自己做一遍，錯的要分類

先自己算，再對解答。做錯的用最下面表格勾原因。

觀念辨識

1. 下列哪組是同類項？
文字要完全一樣才是同類。3x 與 −7x 都是 x，可合併。
2. −(x − 3) 去括號等於？
減號去括號，每項變號：x→−x、−3→+3，得 −x+3。
3. 4a + 5 − a 合併後是？
a 類：4a−a=3a；常數 5 不同類，留著。得 3a+5。

基本計算

① 合併 5x + 2 − 3x + 7
= 2x + 9
x 類 5x−3x=2x；常數 2+7=9。
② (2x2 + x) + (x2 − 3x)
= 3x2 − 2x
加號括號直接去；x2 類 2+1=3，x 類 1−3=−2。
③ (4x − 1) − (x − 6)
= 4x − 1 − x + 6 = 3x + 5
減號括號：−x、+6（−6 變 +6）。這題就是在測去括號變號。
④ (x2 − 2x + 3) − (2x2 + x − 5)
= x2 − 2x + 3 − 2x2 − x + 5 = −x2 − 3x + 8
第二括號三項全變號後再合併。

多項式乘除 · 分配律

外面那個，要乘進去每一項

乘法的根本動作只有一個：分配律。看懂它，後面多項式相乘就是重複做它。

圖
高 a、底 (b+c) 的長方形＝兩塊 a·b + a·c
代數
a(b + c) = ab + ac
白話

括號外面那一個，要分別乘進括號裡的每一項，一項都不能漏。

a(b + c) = ab + ac
例：2x(3x − 4)
= 2x·3x − 2x·4 = 6x2 − 8x
2x 分別乘 3x 和 −4。x·x=x2，所以 2x·3x=6x2。
常見錯誤：只乘第一項，寫成 6x2 − 4，漏了 2x 乘 −4。每一項都要乘到。
多項式乘除 · 相乘

兩個括號：逐項乘，一項不漏

(a+b)(c+d) 就是把前面每一項，分別乘後面每一項，四塊全加起來。

(a+b)(c+d) = ac + ad + bc + bd
例：(x + 2)(x + 3)
= x·x + x·3 + 2·x + 2·3
= x2 + 3x + 2x + 6 = x2 + 5x + 6
四塊乘完，再把同類項（3x、2x）合併。這一步用到了 1-2 的合併同類項。
其實 1-1 的乘法公式就是這個的特例：(x+3)(x+3) 剛好是和的平方、(x+4)(x−4) 剛好是平方差。認得長相就能跳過逐項乘、直接寫答案。
常見錯誤：只乘了「頭乘頭、尾乘尾」兩塊（寫成 x2+6），漏掉中間交叉的兩塊。四塊都要。
多項式乘除 · 相除

除以單項式：每一項各除

先掌握最常考的「多項式÷單項式」，就是把每一項分別除。

(ab + ac) ÷ a = b + c
例：(6x2 + 4x) ÷ 2x
= 6x2÷2x + 4x÷2x = 3x + 2
每一項各自除以 2x。6x2÷2x=3x（次數相減）、4x÷2x=2。
除以「多項式」時要用直式長除法（像整數的長除法，把式子降冪排好再一階一階除）。這個到第3、4章會再用到，之後單獨練。
常見錯誤：只把第一項除、後面照抄，寫成 3x + 4x。每一項都要除到。
練習與訂正

自己做一遍，錯的要分類

先自己算，再對解答。做錯的勾原因。

觀念辨識

1. 3(x + 4) 等於？
3 要乘進每一項：3·x + 3·4 = 3x + 12。
2. x · x2 等於？
同底數相乘，指數相加：x1·x2=x3。
3. (x+1)(x+2) 展開後有幾項要相乘？
前面 2 項 × 後面 2 項 = 4 塊，再合併同類項。

基本計算

① 展開 3x(2x − 5)
= 6x2 − 15x
3x 乘進每一項。
② 展開 (x + 5)(x + 2)
= x2 + 2x + 5x + 10 = x2 + 7x + 10
四塊乘完再合併中間兩項。
③ 展開 (x − 3)(x + 4)
= x2 + 4x − 3x − 12 = x2 + x − 12
注意 −3 的符號，中間 4x−3x=x。
④ (8x2 − 6x) ÷ 2x
= 4x − 3
每項各除以 2x：8x2÷2x=4x、−6x÷2x=−3。
