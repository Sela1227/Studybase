4-1 · 認識

一元二次方程式與它的「解」

先認清楚長相，以及「解」到底是什麼意思。

標準式：ax2 + bx + c = 0　(a ≠ 0)

「一元」＝只有一種未知數 x；「二次」＝最高是 x2。所以 a ≠ 0。若 a=0，它就不再是一元二次方程式；當 b≠0 時會變成一次方程式。解題第一步通常是把所有項移到左邊，整理成標準式。

先整理，才能判斷次數：要把兩邊展開、移項、合併後才看最高次。例如 x2+x = x2+3 兩邊的 x2 消掉後是 x = 3——它其實是一次方程式。看到 x2 不代表就是二次。
例：x2 = 5x 先整理
移項：x2 − 5x = 0（右邊只留 0）

「解」（根）的意思：代進去會讓等式成立的數。例如 x=2 代入 x2−x−2=0：4−2−2=0 ✓，所以 2 是它的解。

好習慣：解完把答案代回原式檢查，等式成立才算對。這章每一題都能自我檢驗，不用等對答案。
4-1 · 核心原理

兩數相乘等於 0，其中至少一個是 0

整章的引擎就這一句。

零乘積性質：若 A × B = 0，則 A = 0 或 B = 0
考卷或老師可能直接說「零乘積性質」——就是這一句：兩因式乘積為 0，至少一個因式為 0。

所以只要把方程式左邊因式分解成「兩個括號相乘 = 0」，每個括號各自等於 0，就得到解。這就是第3章接到這章的地方。

例：x2 = 5x
移項：x2 − 5x = 0
提公因式：x(x − 5) = 0
x = 0　或　x − 5 = 0 → x = 0 或 5
檢驗：0²=5·0 ✓；5²=25=5·5 ✓。兩個都是解。
絕對不要兩邊同除以 x：x2=5x 若兩邊約掉 x 得 x=5，會把 x=0 這個解弄丟（因為 x 可能就是 0，除以 0 不合法）。一律移項、提公因式。
4-1 · 因式分解解

整理 → 分解 → 各括號 = 0

第3章的每一招（提公因式、十字交乘、平方差、完全平方）都能上場。

例（十字交乘）：x2 + 5x + 6 = 0
(x + 2)(x + 3) = 0 → x = −2 或 −3
因式是 (x+p) 時，解是 x = −p（這裡 (x+2)=0 → x=−2）。因式含係數就不能只變號：要把因式設為 0 再解一次方程式（見下面含係數的例子）。
例（平方差）：x2 − 9 = 0
(x + 3)(x − 3) = 0 → x = 3 或 −3
例（完全平方＝重根）：x2 − 6x + 9 = 0
(x − 3)2 = 0 → x = 3（兩個解重疊，叫「重根」）
例（首項係數不是 1）：2x2 + 5x + 2 = 0
含係數十字交乘（第3章）：(2x + 1)(x + 2) = 0
2x + 1 = 0 → x = −1/2　；　x + 2 = 0 → x = −2
(2x+1)=0 的解是 −1/2，不是 −1——因式含係數時，把它當一個小方程式解，不能只把常數變號。
先整理成「= 0」再分解：像 x(x+1)=6 不能直接寫 x=6 或 x+1=6——右邊是 6 不是 0，AB=0 的原理用不上。要先展開移項成 x2+x−6=0 再分解。

4-2 · 直接開平方

A2 = k：開根號，正負都要

當方程式可以整理成「某個式子的平方 ＝ 常數」（A2 = k）時，就能直接開平方——這裡用到第2章的平方根。

A2 = k　(k > 0) → A = ±√k
A 可以是整個式子：x、x−1、2x+3 都行——只要左邊是「某東西的平方」、右邊是常數，就整塊開根號。
三種情況：k > 0 → 兩個解 A=±√k；k = 0 → A=0（重根）；k < 0 → 沒有實數解（沒有數平方後是負的）。
例：x2 = 25　；　(x − 1)2 = 5
x = ±5
x − 1 = ±√5 → x = 1 + √5 或 1 − √5（合寫 x = 1 ± √5）
「整個括號」當成一塊開根號，再把 1 移過去。答案是根式就照第2章化到最簡。
最常錯：x2=9 只答 x=3。負的 −3 平方也是 9，兩個解都要。
適用範圍：只有「A2 = k」的形狀才能直接開平方。像 x2+3x+1=0 沒有整理成平方＝常數，不能直接開根號——要先配方（下一課）或用公式解。
4-2 · 配方法

自己把式子「湊」成完全平方

拆不開的，就把左邊湊成 (x+□)2，再直接開平方。

x2 + bx 想配成完全平方，要補 (b/2)2
例：解 x2 + 4x − 3 = 0
① 常數移右：x2 + 4x = 3
② 兩邊同加 (4/2)2 = 4：x2 + 4x + 4 = 7
③ 左邊變完全平方：(x + 2)2 = 7
④ 開平方：x + 2 = ±√7 → x = −2 ± √7
補的數是「x 係數一半的平方」。兩邊要同加，等式才不變。這裡用到第1章的 (a+b)²。
例（奇數係數也一樣配）：x2 + 3x − 1 = 0
x2 + 3x = 1 → 兩邊加 (3/2)2 = 9/4
(x + 3/2)2 = 1 + 9/4 = 13/4
x + 32 = ±√132 → x = −3 ± √132
「係數一半再平方」對奇數一樣成立，只是會出現分數——照規則走就好，不要怕分數。
例（x2 前有係數）：2x2 + 8x − 1 = 0
先讓 x2 係數變 1：方程式兩邊同除以 2 → x2 + 4x − 1/2 = 0
x2 + 4x = 1/2 → 兩邊加 4 → (x + 2)2 = 9/2
x + 2 = ±3√22 → x = −2 ± 3√22
√(9/2) 照第2章有理化成 3√2/2。「除以係數」是兩邊同除，右邊也要除。
為什麼補的是 (b/2)2？看面積就懂
x2 + 4x ＝ 一個 x×x 正方形 ＋ 兩條 2×x 長方形（4x 平分成兩條）
右下角缺一塊 2×2 = 4——補上它，整個就拼成 (x+2)2
補的那塊邊長正好是「x 係數的一半」，面積就是 (b/2)2。圖以正數示意；代數對正負與 0 都成立。
常見錯：只在左邊加 (b/2)²、右邊忘了加——等式就被改掉了。永遠「兩邊同加」。
4-2 · 公式解

把配方法做一次到底，就是公式解

對一般的 ax2+bx+c=0 走一遍配方法，得到的通用結果就是公式解——背它，等於把配方法隨身攜帶。

公式解怎麼來？（把配方法真的做一次到底）
① ax2+bx+c = 0，兩邊乘 4a：4a2x2 + 4abx + 4ac = 0
② 常數移右、兩邊補 b2：4a2x2 + 4abx + b2 = b2 − 4ac
③ 左邊是完全平方：(2ax + b)2 = b2 − 4ac
④ 開平方：2ax + b = ±√(b2−4ac)
⑤ 解出 x = −b ± √(b2−4ac)2a
這一趟同時解釋了四件事：分母為什麼是 2a（把 2ax 的 2a 除過去）、根號裡為什麼是 b2−4ac（步驟②右邊）、± 從哪來（步驟④開平方）、以及判別式為什麼能決定解的個數（根號裡的正負零）。
x = −b ± √(b2−4ac)2a　(a ≠ 0)
判別式 b2−4ac解的情況
> 0兩個相異實數解
= 0一個相異實數解（兩根相等，稱重根）：x = −b/(2a)
< 0沒有實數解
公式解五步：① 整理成 ax²+bx+c=0　② 列 a、b、c（連正負號；缺項寫 0）　③ 先算判別式　④ 代公式　⑤ 化簡根式
例：解 2x2 + 3x − 1 = 0
係數數值
a2
b3
c−1
b2−4ac = 9 − 4·2·(−1) = 9 + 8 = 17
x = −3 ± √174
c 是 −1，代入 −4ac 時是 −4·2·(−1)=+8——符號是公式解最大的失分點，建議先把 a、b、c 連同正負寫下來再代。
缺項寫 0：2x2 − 5 = 0 的係數是 a=2、b=0、c=−5——跟第1章「缺項係數為 0」同一個觀念。
例（判別）：x2 + 2x + 5 = 0 有幾個實數解？
b2−4ac = 4 − 20 = −16 < 0 → 沒有實數解
固定判斷流程：先整理 → 能不能直接開平方（已是 A²=k）→ 能不能因式分解 → 否則用公式解（一般情況皆可用）。配方法在題目指定、或式子好湊平方時使用。不同方法答案一定一樣。

4-2 · 實戰

配方的兩個地雷、除法的一個地雷

題型一 · 配方求 (x+a)² = b 的 b
例①【核心必會】2x²+4x−3 = 0 寫成 (x+a)² = b，求 b
先整個除以首項係數 2：x²+2x = 32
加「一次項係數一半的平方」＝ 1²：(x+1)² = 32 + 1 = 52
兩個地雷：① 忘了先除首項係數就配方　② 「一半」取的是除完之後的一次項係數的一半。b = 常數移過去＋(一半)²。
例②【核心必會】配方解 x²−6x = 91
(x−3)² = 91+9 = 100 → x−3 = ±10 → x = 13 或 −7
開平方那步 ± 兩個都要——大數字（91、192）就是提示你走配方，不用十字交乘硬試。
題型二 · 步驟找錯：除以未知數會丟根
例③【核心必會】解 5x − 2x² = 0，小安的步驟：①移項 5x = 2x²　②兩邊除以 x 得 5 = 2x　③x = 5/2。哪步開始錯？
錯在步驟②——除以 x 時默認 x ≠ 0，把 x = 0 這個根丟掉了
正解：提公因式 x(5−2x) = 0 → x = 0 或 5/2
方程式兩邊不能除以含未知數的式子（它可能是 0）。有公因式就提出來用 AB=0，兩個根一個都不少。
例④【進階】配方步驟找錯：解 4x²−5x−3 = 0，步驟一 x²−54x = 34；步驟二 兩邊加 (52)²。對嗎？
錯——除以 4 之後一次項係數是 −5/4，該加的是它的一半 (58)² 的平方，不是原式 −5 的一半
找錯題的檢查點固定三個：①首項除乾淨了嗎　②加的是「現在的係數」一半的平方嗎　③開平方有 ± 嗎。逐步對，錯的那步就現形。

4-3 · 應用問題

設 → 列 → 解 → 驗（捨去不合理的解）

應用題比計算題多兩步：把文字翻譯成方程式（列），和把不合理的解丟掉（驗）。

① 設未知數 → ② 依題意列式 → ③ 解方程式 → ④ 檢驗：解合不合題意？不合的捨去
例①【核心必會】兩個連續正整數的乘積是 72，求這兩個數
量代數表示
較小整數x
較大整數x+1
乘積x(x+1)
題目條件x(x+1) = 72
展開移項：x2 + x − 72 = 0 → (x + 9)(x − 8) = 0 → x = −9 或 8
題目說「正整數」→ 捨去 −9 → x = 8 → 答案是 8 和 9
方程式會給兩個解，但題目情境常常只收一個。「捨去」要寫出理由（負數不是正整數）。
例②【核心必會】長方形的長比寬多 3 公分，面積 40 平方公分，求長寬
量代數表示
寬x
長x+3
面積x(x+3)
題目條件x(x+3) = 40
x2 + 3x − 40 = 0 → (x + 8)(x − 5) = 0 → x = −8 或 5
邊長必須為正 → x = 5 → 寬 5、長 8 公分
例③【進階】正方形邊長增加 3 公分後，面積變成 64 平方公分，求原邊長
(x + 3)2 = 64 → x + 3 = ±8 → x = 5 或 −11
邊長為正 → 原邊長 5 公分
這題直接開平方最快——選方法也是練習的一部分。
最常見的失分：解出兩個根就照抄，忘了回頭對題意。長度、人數、年齡…不能是負的；「捨去」那一行一定要寫、要給理由。
但捨去不是機械規則：要不要捨，看未知數代表什麼。長度、人數不能為負；溫度變化、座標、盈虧就可能是負的。也有題目兩個根都合題意——每個根逐一檢驗，不是「負的永遠丟掉」。
4-3 · 實戰一

根與係數：不解出根，也能算

x² + px + q = 0 的兩根 α、β：α+β = −p　；　αβ = q
題型三 · 估根範圍，拆絕對值
例①【進階】a、b 為 x²−4x+2 = 0 的兩根（a＞b），求 |a−4| + |b−1|
根 = 2±√2；√2≈1.41 → a ≈ 3.41、b ≈ 0.59
判正負：a−4 ＜ 0 → |a−4| = 4−a；b−1 ＜ 0 → |b−1| = 1−b
和 = (4−a)+(1−b) = 5−(a+b) = 5−4 = 1（a+b 用根與係數）
三步：估根區間 → 判每個絕對值內的正負 → 去絕對值後用 a+b、ab 收尾。根號常會整組消掉——那就是這類題的設計。
題型四 · 兩根有特殊關係（a² = b 型）
例②【進階】x²+px−8 = 0 的兩根為 a、b 且 a² = b，求 p
積：ab = a·a² = a³ = −8 → a = −2 → b = 4
和：a+b = 2 = −p → p = −2
特殊關係先丟進「積」裡（次數會變好算的立方），解出根後再用「和」求係數。
題型五 · 倒數根的新方程式
例③【進階】x²−bx+c = 0 兩根 α、β（αβ≠0）；x²−mx+n = 0 兩根為 1/α、1/β，m、n 與 b、c 的關係？
m = 1/α + 1/β = (α+β)/(αβ) = b/c；n = 1/(αβ) = 1/c（即 cn = 1）
倒數和 = 和÷積——通分就出來。驗算最快：拿 x²−3x+2（根 1、2）→ 倒數根 1、1/2 → 新和 3/2 = b/c ✓、新積 1/2 = 1/c ✓。抽象題用具體數字驗一次。
題型六 · 兩根皆質數
例④【進階】x²−24x+k = 0 兩根皆為質數，且一根小於 7，求 k
兩根之和 = 24。列小於 7 的質數：2、3、5 → 配對 22（✗ 非質數）、21（✗）、19（✓ 質數）
→ 兩根 5、19 → k = 積 = 95
和是偶數 → 兩根「同奇偶」：都是奇質數，或含 2。逐一檢查候選，配到質數為止——質數表 2、3、5、7、11、13… 要在手邊。
4-3 · 實戰二

幾何應用：列完方程式，捨根才是勝負

流程：設未知數 → 畢氏／面積列式 → 解一元二次 → 捨根（檢查範圍）→ 回答所問
題型七 · 兩個根，哪個合法？
例①【核心必會】竹竿長 L：水平比門寬多 8、垂直比門高多 1、斜拿剛好等於對角線。列式並求 L
門寬 = L−8、門高 = L−1 → 畢氏：L² = (L−8)² + (L−1)²
整理：L²−18L+65 = 0 → (L−5)(L−13) = 0 → L = 5 或 13
檢查：門寬 = L−8 必須 ＞ 0 → L ＞ 8 → 捨 5 → L = 13
捨根的依據寫清楚：不是「捨小的」，是「代回題意檢查」——L=5 會讓門寬變負，物理上不存在。
例②【進階】正方形 ABCD 邊長 1，BE = DF = x，△AEF 為正三角形，求 x
AE² = 1+x²（△ABE 畢氏）；EF² = 2(1−x)²（△ECF 兩股都是 1−x）
正三角形 → AE² = EF²：1+x² = 2(1−x)² → x²−4x+1 = 0 → x = 2±√3
x 是邊上的一段 → 0 ＜ x ＜ 1 → 捨 2+√3 → x = 2−√3
√3≈1.73 → 2−√3≈0.27 ✓ 在範圍內。幾何題的根一定要跟「長度範圍」對一次。
題型八 · 誤算問題：兩種算法同答案
例③【核心必會】正數 n 平方減 4 是正確答案；小美誤把平方看成乘 2、減 4 看成加 4，居然也對。正確答案是多少？
兩種算法相等：n²−4 = 2n+4 → n²−2n−8 = 0 → (n−4)(n+2) = 0 → n = 4（n 為正數，捨 −2）
題目問「正確答案」= n²−4 = 12（不是 n！）
答案對象檢查：解出 n 只是半路——題目問的是那個「答案」，還要代回去算一次。
題型九 · 黃金比例與公式解近似（★）
例④【挑戰】黃金比例的列式骨架：下半身 c、全身 h，墊高 x 後滿足「下：上 = 全：下」
比例式交叉相乘 → (c+x)² = 上半身 × (h+x) → 展開成一元二次 → 公式解
根號裡的大數用題目給的近似值（題目會附 √N ≒ …），取正根、四捨五入
這類題考的是「把比例翻譯成方程式」＋「公式解配近似值」——列式對了，後面就是流程。

基本計算

① 兩個連續正偶數的乘積是 48，求這兩個數
x(x+2)=48 → (x+8)(x−6)=0 → x=6（捨 −8）→ 6 和 8
驗算兩件事：x=6 是正偶數 ✓（設 x、x+2 只保證差 2，最後要檢查真的是偶數）、6×8=48 ✓。
② 長方形的長比寬多 5 公尺，面積 36 平方公尺，求長寬
x(x+5)=36 → (x+9)(x−4)=0 → x=4（捨 −9）→ 寬 4、長 9 公尺
③ 正方形邊長增加 3 公分後面積為 100 平方公分，求原邊長
(x+3)2=100 → x+3=±10 → x=7（捨 −13）→ 原邊長 7 公分
④ 兩個連續正奇數的乘積是 63，求這兩個數
x(x+2)=63 → (x+9)(x−7)=0 → x=7（捨 −9）→ 7 和 9
檢查 7 是正奇數 ✓。另一種設法：連續偶數設 2n、2n+2，連續奇數設 2n+1、2n+3——一開始就保證奇偶，但式子稍長。兩種都對，挑順手的。
⑤ 三角形的底比高多 2 公分，面積 24 平方公分，求底和高
設高 x、底 x+2 → x(x+2)/2 = 24 → x2+2x−48=0 → x=6（捨 −8）→ 高 6、底 8 公分
先寫面積公式（底×高÷2）再列式——圖形題都是「公式先行」。
⑥【進階選做】長方形的長比寬多 2 公尺，面積 20 平方公尺，求長與寬（答案不是整數）
x(x+2)=20 → x2+2x−20=0 → 公式解：x = −2 ± √842 = −1 ± √21；邊長為正 → 寬 = √21 − 1、長 = √21 + 1 公尺
應用題的答案不一定是漂亮整數——分解不了就用公式解，這正是 4-2 接到 4-3 的地方。√84=2√21 記得化簡。
⑦ 某數的平方等於「5 倍該數減 6」，求該數
x2 = 5x − 6 → (x−2)(x−3)=0 → x = 2 或 3（兩個都合題意）
這題沒有負根可捨——逐一檢驗：2²=10−6 ✓、3²=15−6 ✓。捨不捨看題意，不是機械丟負的。
