國二上 · 第3章 因式分解

把「展開」反過來做

因式分解就是第1章「乘法公式／展開」的反向——把一個多項式寫回「幾個式子相乘」。第4章一元二次方程式要靠它來解，是很關鍵的一塊。第1章熟的話，這章會順很多。

前置：第1章 乘法公式與多項式接到第4章 一元二次方程式預計 40 分鐘／節
因式分解 · 意義

因式分解是「展開」的反向

第1章把括號乘開叫「展開」；反過來，把式子寫回「相乘」的形式，就叫因式分解。

展開：(x+2)(x+3) → x2+5x+6
因式分解：x2+5x+6 → (x+2)(x+3)
因式分解 = 把多項式寫成「幾個因式相乘」（展開的反向）
還記得第1章的反向辨識嗎？x2+6x+9=(x+3)2、x2−16=(x+4)(x−4)——那時只要「看得出來」；這章要能自己「分出來」。
兩個重點：① 結果一定是「相乘」，不是相加。② 要在本章的整數係數範圍內，分到每個因式都不能再分為止。分完可以乘回去驗算，等於原式才對。
因式分解 · 提公因式

每一項都有的，提到括號外

最先要做的一步：先看每一項有沒有「共同的因式」，有就提出來。

找出各項的公因式（共同的數字與文字），提到括號外
例：6x2 + 9x
兩項的公因式：數字 3、文字 x → 公因式 3x
6x2 + 9x = 3x(2x + 3)
提出 3x 後，括號裡是「原式各項 ÷ 3x」：6x²÷3x=2x、9x÷3x=3。乘回去 3x·2x+3x·3=6x²+9x ✓。
例：4x2 − 8x
= 4x(x − 2)
例（次方較高）：12x3 + 18x2
數字最大公因數 6；文字取每項都有的最低次方 x2
= 6x2(2x + 3)
規則：數字取最大公因數；共同文字取最低次方。
例（整個括號也是公因式）：x(x+2) + 3(x+2)
兩項共同的因式是整個 (x+2)
= (x + 2)(x + 3)
「因式」不一定是數字或單一文字，也可以是一整個括號。
提「最大」的公因式：4x2−8x 若只提 2 得 2(2x²−4x)，括號裡還能再提，沒分完。要一次提到 4x。分完習慣乘回去檢查。
因式分解 · 乘法公式反用

把第1章的公式反過來用

認出式子是某個乘法公式展開的結果，就能直接寫回相乘的形式。

a2+2ab+b2 = (a+b)2　；　a2−2ab+b2 = (a−b)2　；　a2−b2 = (a+b)(a−b)
例（完全平方）：x2 + 6x + 9
首項 x2、末項 9=32，中間 6x = 2·x·3 ✓
= (x + 3)2
認完全平方：首尾都是平方，中間剛好等於 2×√首×√尾。
例（差的完全平方）：x2 − 10x + 25
首項 x2、末項 25=52，中間 −10x = −2·x·5 ✓
= (x − 5)2
中間項是「負」的，括號裡就是減號。中間項的正負決定 (a+b)² 還是 (a−b)²。
例（含係數）：4x2 − 12x + 9
(2x)2、32，中間 −12x = −2·(2x)·3 ✓ → = (2x − 3)2
反例（很像但不是）：x2 + 6x + 8
末項 8 ≠ 32，不是完全平方 → 改用十字交乘
積 8、和 6 → 2、4 → = (x + 2)(x + 4)
公式認不出來時不要硬套，換十字交乘。這就是下一節的方法。
例（平方差）：x2 − 16
= x2 − 42 = (x + 4)(x − 4)
例（含係數的平方差）：4x2 − 25
= (2x)2 − 52 = (2x + 5)(2x − 5)
平方差是「相減」才行：x2+16 是平方「和」，不能用平方差公式；在本章整數係數範圍內不再分解。

十字交乘 · 基本型

x2+bx+c：找兩數，積 c、和 b

分解前四項檢查：① 降冪排列　② 提公因式　③ 處理負號或分數（提出 − 或公分母分之一）　④ 再選分解法
看到式子先別急著十字交乘——四項檢查掃一遍，很多「怪式子」整理完就變回熟悉的標準型。

二次三項式先看是不是完全平方；不是的話，再找整數因數做十字交乘：把 x²+bx+c 拆成 (x+p)(x+q)。找不到合適的整數組合時，在本章範圍就可能不能再分解。

x2+bx+c = (x+p)(x+q)，其中 p×q = c、p+q = b
例：x2 + 5x + 6
找兩數：相乘 = 6、相加 = 5 → 是 2 和 3
x ＼＿ +2 x ＿／ +3 ──────────── 直乘 x·x = x²，(+2)·(+3) = +6 交叉相加 3x + 2x = +5x ✓
= (x + 2)(x + 3)
例（含負號）：x2 − 5x + 6
積 = 6（正）、和 = −5（負）→ 兩個都負：−2、−3
= (x − 2)(x − 3)
例（積為負）：x2 + x − 6
積 = −6、和 = +1 → 一正一負：+3、−2
= (x + 3)(x − 2)
符號快判：積為正 → 兩數同號（看和決定正負）；積為負 → 兩數一正一負（絕對值大的跟著和的符號）。
非例：x2 + x + 1（找不到就是找不到）
要積 = 1、和 = 1 的整數：1×1=1 但 1+1=2 ✗；(−1)×(−1)=1 但 −1−1=−2 ✗
→ 沒有整數組合，在本章整數係數範圍不能用十字交乘分解
不是每個二次三項式都拆得開。試完主要組合都不合，就寫「不能分解（整數範圍）」，不要硬湊。
一定要驗算：把 (x+p)(x+q) 乘回去，中間項對了才算對。符號最容易錯。
十字交乘 · 含係數

ax2+bx+c：首項係數也要拆

首項係數不是 1 時，左邊要拆首項係數、右邊拆常數，交叉相乘相加要等於中間項。

例：2x2 + 7x + 3
2x ＼＿ +1 → 交叉 2x·3 = 6x x ＿／ +3 → 交叉 x·1 = x ────────────── 直乘 2x·x = 2x²，1·3 = +3 交叉相加 6x + x = +7x ✓
= (2x + 1)(x + 3)
左行相乘要得首項 2x²、右行相乘要得常數 3、交叉相乘相加要得中間 7x。三個都對才成立。
例：3x2 + 5x − 2
試 (3x−1)(x+2)：直乘 3x²、−2；交叉 6x−x=5x ✓
= (3x − 1)(x + 2)
例（要試好幾組）：6x2 + 11x + 3
首項 6x² 可拆 6x·x 或 3x·2x；常數 3 可拆 1·3 或 3·1
試 (6x+1)(x+3)：交叉 18x+x=19x ✗；試 (3x+3)(2x+1)：交叉 3x+6x=9x ✗
試 (3x+1)(2x+3)：交叉 9x+2x=11x ✓ → = (3x + 1)(2x + 3)
拆法不只一組時就是要試。每試一組都算交叉和，對了才停。
可能要試幾組：首項、常數的拆法不只一種，找到「交叉相加＝中間項」的那組才對。每次都乘回去驗算。
因式分解 · 混合分解與流程

提公因式不是一種題型，是每題的第一步

真正的考題常常要「先提，再繼續分」。提完公因式，括號裡還要再看一次。

因式分解四步驟：① 整理 → ② 先找公因式 → ③ 看形式（兩項→平方差；三項→完全平方→十字交乘）→ ④ 每個因式再檢查，最後乘回去驗算
式子的情況優先方法
各項有共同因式先提公因式
兩項且為平方相減平方差
三項、首尾平方、中間 ±2ab完全平方
可用整數因數配出中間項十字交乘
分完後因式仍可分繼續分解
例（提完接平方差）：2x2 − 18
先提 2：= 2(x2 − 9)
括號裡還是平方差：= 2(x + 3)(x − 3)
寫成 2(x²−9) 還沒完成——x²−9 還能分。步驟④就是在抓這個。
例（提完接完全平方）：3x2 + 12x + 12
= 3(x2 + 4x + 4) = 3(x + 2)2
例（提完接十字交乘）：2x2 + 10x + 12
= 2(x2 + 5x + 6) = 2(x + 2)(x + 3)
最常見的失分：提完公因式就交卷。括號裡的式子要再走一次步驟③，直到每個因式都不能再分。
3-2 · 實戰題型

因式分解的六張考卷臉

這些題型在你的考卷出現過。共通心法：看到「面積、邊長、因式」，先把式子分解乾淨，再回頭對圖或對選項。

題型一 · 剪拼幾何＝平方差的圖形版
例①【核心必會】邊長 2x 的正方形剪去邊長 5 的正方形，剩餘拼成一邊為 2x−5 的長方形，另一邊？
面積不變：(2x)² − 5² = (2x−5)(2x+5) → 另一邊 = 2x + 5
剪拼前後面積相等——平方差公式就是這張圖。一邊是 (2x−5)，另一邊必是 (2x+5)，不用真的算圖形。
題型二 · 分組分解求邊長
例②【進階】甲、乙兩長方形併排（共同邊 EF）。甲面積 = xy−2x−y+2、乙面積 = xy−2x+y−2，PE = x−1，求 EF
甲：xy−2x−y+2 = x(y−2) − (y−2) = (x−1)(y−2)
甲 = PE × EF = (x−1) × EF → EF = y − 2
驗證：乙 = xy−2x+y−2 = (x+1)(y−2) —— 共同邊 (y−2) ✓，乙的另一邊 x+1
四項式先分組提公因式；分解出的兩個因式就是長方形的兩邊。已知一邊（PE），面積除掉它，另一邊自己現身。分完用另一塊驗證共同邊——對就對得很安心。
題型三 · 「何者是因式」——先展開整理再分解
例③【核心必會】下列何者是 (x+2)(2x+1) − 5 的因式？
先展開：2x²+5x+2−5 = 2x²+5x−3 → 十字交乘 = (2x−1)(x+3)
不能直接看括號猜——(x+2) 不是因式（−5 破壞了它）。
原式裡看得到某個括號，不代表它是整個多項式的因式。括號乘積後面還有加減其他數時，一律先去括號、合併，再重新分解——因式只認分解後的結果。
題型四 · 面積與一邊已知，求另一邊
例④【進階】長方形面積 4x²−10x−6，x 為整數，一邊長 15，另一邊可能是？
先分解（記得提公因式）：= 2(2x+1)(x−3)
試一邊 = 15：2x+1 = 15 → x = 7 → 另一邊 = 2(x−3) = 8
流程：分解 → 把 15 對到其中一個因式（或因式組合）→ 解出 x → 代入剩下的因式。x 要是整數——對不出整數就換一種拼法。
題型五 · 完全平方定係數：± 兩解都要
例⑤【進階】4x² + (k−1)x + 9 可分解成一次式的平方，求 k
= (2x ± 3)²，中間項 = ±2·2x·3 = ±12x → k−1 = 12 或 k−1 = −12
→ k = 13 或 −11（兩個都是答案）
完全平方的中間項有 + 和 − 兩種——只寫一個就漏一半。之後題目常拿兩解（a、b）再加工（如求 a−2b），照條件 a＞b 分配好再算。
題型六 · 大數計算：設 x、分解、約分
例⑥【核心必會】(99³ + 2×99² + 99) ÷ (99² + 99) = ?
設 x = 99：原式 = (x³+2x²+x)/(x²+x) = x(x+1)²/[x(x+1)] = x+1
代回：= 100
巨大數字先別代（第1章的老口訣）——設 x、上下各自分解到底、整組約分，最後才代回。紅線：約分只能約掉「完整的因式」，不能跨越加減號約掉單獨的項（x²+x 裡的 x 不能單獨跟分子的 x 對消——要先分解成 x(x+1) 才約得動）。
3-2 · 實戰題型二

式子長得怪怪的？先整形，再分解

題型七 · 負首項：先提「−」再分解
例①【核心必會】10 − 3x − x² 的因式有哪些？
先按降冪提負號：= −(x² + 3x − 10) = −(x+5)(x−2)
首項是負的（或次序亂的）先整理成 −(標準式)。注意 (x−2) 是因式、(2−x) 也是因式——因為 (2−x) = −(x−2)，差一個負號仍算因式。選項出現 (15−2x) 這種樣子時別慌，它就是 −(2x−15)。
題型八 · 分數係數：先提公分母
例②【核心必會】因式分解 12x² + 32x − 5
提出 12：= 12(x² + 3x − 10) = 12(x+5)(x−2)
分數係數先提「公分母分之一」，括號裡變整數係數再十字交乘。提出來的分數要留在答案前面，不能弄丟。
題型九 · 分解對不對？「三查」檢驗法
三查：① 首項係數的積　② 常數項的積（含符號）　③ 中間項＝交叉相乘的和
例③【核心必會】8x² − 10x + 3 = (2x−1)(4x−3) 對嗎？6x² − 7x + 2 = (3x+2)(2x+1) 呢？
第一個：首項 2×4=8 ✓；常數 (−1)(−3)=3 ✓；中間 2·(−3)+4·(−1) = −10 ✓ → 對
第二個：首項 ✓ 常數 ✓，但中間 3+4 = +7 ≠ −7 → 錯（正確是 (3x−2)(2x−1)）
「何者錯誤」型不用每個重新分解——三查掃過去，最常錯在符號（常數對了、中間項的正負反了）。有提公因式的（如 3(…)(…)）記得把提出來的數乘回去一起查。
題型十 · 公因式：兩式各自分解，找共同的
例④【核心必會】M = 3x²+5x+2、N = x²−1，求 M 與 N 的公因式
M = (3x+2)(x+1)；N = (x+1)(x−1) → 公因式 = x+1
多項式的公因式跟整數的公因數一樣：各自分解成「質因式」，取共同的。不用試除選項。
題型十一 · 拼板題：塊數當係數
a 塊 x×x ＋ b 塊 x×1 ＋ c 塊 1×1 拼成長方形 ⇔ ax²+bx+c 可分解；兩邊長 = 兩個因式
面積相同只是必要條件，不是充分條件——選項面積可能全部一樣，仍必須用因式分解確認紙片真的能依「因式所代表的邊長」排列。
例⑤【進階】2 塊邊長 4 的正方形、5 塊 4×1、2 塊 1×1，拼成的長方形是？
設 x=4：2x²+5x+2 = (2x+1)(x+2) → 邊長 = 2×4+1 = 9 與 4+2 = 6 → 9 × 6
驗算：2×16+5×4+2 = 54 = 9×6 ✓
十字交乘的圖形版！「拿掉一塊才能拼成」的變形：把 ax²+bx+c 各扣一塊逐一試，能分解（判別式為完全平方）的那組就是答案。
題型十二 · 分解＋正整數範圍計數
例⑥【進階】正整數 a、b 滿足 a²+2a−8 = b 且 b ＜ 50，數對 (a,b) 有幾組？
分解：(a+4)(a−2) = b。b 為正整數 → a−2 ≥ 1 → a ≥ 3
逐列：a=3→7、4→16、5→27、6→40 ✓；a=7→55 ＞ 50 ✗ → 4 組
先分解看出「a 從哪裡開始合法」（b 要正 → a≥3），再逐列到超過上限為止——跟第2章的範圍篩同一個精神：列出來，不多不漏。
整章一條流程：先整理（四項檢查）→ 選方法 → 完整分解 → 展開檢查（三查） → 套回題意（邊長？因式？個數？）。分解不是終點——題目問什麼，最後一步就翻譯成什麼。

觀念辨識（答錯可再選）

1. x2+7x+12 要找積 12、和 7 的兩數，是？
3×4=12、3+4=7 ✓ → (x+3)(x+4)。
再看一次，選出正確的。
2. x2−2x−8 分解後是？
積 −8、和 −2 → −4、+2 → (x−4)(x+2)。
再看一次，選出正確的。
3. 分解 2x2+7x+3：左側由上到下排 2x、x，右側由上到下哪一組能使交叉和為 7x？
右側上 1、下 3：交叉 2x·3 + x·1 = 6x + x = 7x ✓。若排 3、1：交叉 2x·1+x·3=5x ✗。十字交乘重點是「排列」，不是只知道 3=1×3。
再看一次，選出正確的。

基本計算

① 分解 x2 + 8x + 15
= (x + 3)(x + 5)
積15、和8 → 3、5。
② 分解 x2 − 7x + 10
= (x − 2)(x − 5)
積10、和−7 → −2、−5。
③ 分解 x2 + 2x − 15
= (x + 5)(x − 3)
積−15、和+2 → +5、−3。
④ 分解 2x2 + 5x + 2
= (2x + 1)(x + 2)
交叉 4x+x=5x ✓。
⑤ 分解 2x2 − 8（先提再分）
= 2(x2 − 4) = 2(x + 2)(x − 2)

重複錯題型・無提示練習（不給方法，自己判斷）：

⑦ 邊長 5x 的正方形剪去邊長 4 的正方形，剩餘拼成一邊為 5x−4 的長方形，另一邊？
(5x)²−4² = (5x−4)(5x+4) → 5x+4
剩餘面積 = 新長方形的長 × 寬。
⑧ 4x²+(k+2)x+25 可分解成一次式的平方，k 可能為 a 或 b（a＞b），求 a−b
(2x±5)² 中間 = ±20x → k+2 = ±20 → k = 18 或 −22 → a−b = 18−(−22) = 40
⑨ 兩長方形併排組成大長方形，面積分別為 pq−3p−q+3 與 pq−3p+q−3，共同邊為 q−3 的鄰邊 PE = ?（即求另一塊的資訊前，先分解第一塊）
pq−3p−q+3 = p(q−3)−(q−3) = (p−1)(q−3) → 兩邊為 p−1 與 q−3
分組分解出的兩個因式就是兩邊——重排、分組、提括號，一氣呵成。

錯題再測（考卷原題——先自己完整作答，再開解答；標【進階】者選做）：

再測① 邊長 3x 的正方形剪去邊長 7 的正方形，剩餘拼成一邊為 3x−7 的長方形，另一邊？
(3x)²−7² = (3x−7)(3x+7) → 3x + 7
再測②【進階】長方形 PQRS 由甲、乙組成，甲面積 = 1−a−b+ab、乙面積 = ab+a−b−1（長寬皆大於 1），PE = b−1，求 EF
甲：1−a−b+ab = (1−a) − b(1−a) = (1−a)(1−b) = (a−1)(b−1)（長寬＞1，取正因式）
甲 = PE × EF = (b−1)·EF → EF = a − 1；驗證：乙 = a(b+1)−(b+1) = (a−1)(b+1) ✓ 共同邊 a−1
「長與寬都大於 1」這句話就是要你把 (1−a)(1−b) 換成正的 (a−1)(b−1)——題目每句話都有用。
再測③ 計算 (1998³ + 3×1998² + 2×1998) ÷ (1998² + 1998)
設 x = 1998：x(x+1)(x+2) / [x(x+1)] = x+2 = 2000
分子 x³+3x²+2x = x(x²+3x+2) = x(x+1)(x+2)——先提 x 再十字交乘，兩步都要做完才約得動。
再測④ 長方形面積 12x²−50x+8，x 為整數，一邊 35，另一邊可能為？(A) 8 (B) 6 (C) 4 (D) 2
= 2(6x−1)(x−4)；6x−1 = 35 → x = 6 → 另一邊 = 2(x−4) = 4 → (C)
35 也可以試 5×7 等組合，但只有 6x−1=35 給整數 x。逐一檢查、對出整數才收。
再測⑤【進階】9x²−(m−3)x+4 可分解成一次式的平方，m 可能為 a 或 b（a、b 為整數，a＞b），求 a−2b
= (3x±2)²，中間 = ±12x → −(m−3) = 12 → m = −9；−(m−3) = −12 → m = 15
a = 15、b = −9（a＞b）→ a−2b = 15+18 = 33
注意中間項是 −(m−3)，負號要跟著走；± 兩解都列出來再按 a＞b 分配。
再測⑥ 下列何者是 (x+1)(2x+3)−10 的因式？(A) 2x+7 (B) x+1 (C) x+2 (D) 2x−5
展開：2x²+5x+3−10 = 2x²+5x−7 = (2x+7)(x−1) → (A)
你上次選 (B) x+1——括號裡的 (x+1) 在減 10 之後已經不是因式了。「先展開整理、再分解」，因式只認分解後的。
再測⑦ 下列何者是 12−4x−x² 的因式？(A) x+1 (B) x−2 (C) x+3 (D) x−4
= −(x²+4x−12) = −(x+6)(x−2) → (B) x−2
再測⑧ 因式分解 12x² + 114x − 10
提 14：= 14(2x²+11x−40) = 14(2x−5)(x+8)（選 C）
公分母是 4，提 1/4 括號內才全是整數。
再測⑨ 下列何者是 4a²−(a+3)(a−2)−10 的因式？
先展開合併：= 4a²−(a²+a−6)−10 = 3a²−a−4 = (3a−4)(a+1) → (B) 3a−4
跟題型三同一招：有減式先展開整理，因式只認合併後的。
再測⑩ 下列因式分解何者錯誤？(A) 380−x−x²=−(x+20)(x−19) (B) −2x²−x+120=(x+8)(15−2x) (C) 4x²+5−12x=(2x−1)(2x−5) (D) 36x²−39x+9=3(3x+1)(4x+3)
用三查掃 (D)：36x²−39x+9 = 3(12x²−13x+3)——中間項應為負，3(3x+1)(4x+3) 展開中間是 +39x → (D) 錯（正確：3(3x−1)(4x−3)）
(B) 的 (15−2x) = −(2x−15)，配上負首項剛好對——「長得怪」不等於錯，三查說了算。
再測⑪ M = 2x²+3x+1、N = 4x²−4x−3，M 與 N 的公因式？
M = (2x+1)(x+1)；N = (2x+1)(2x−3) → (D) 2x+1
再測⑫【進階】6 塊邊長 4 的正方形、7 塊 4×1 長方形、2 塊 1×1 正方形，可拼成哪種長方形？(A) 14×9 (B) 18×7 (C) 21×6 (D) 42×3
設 x=4：6x²+7x+2 = (3x+2)(2x+1) → 邊長 14 與 9 → (A)
總面積 96+28+2 = 126 = 14×9 ✓（B、C、D 面積都是 126，但只有因式代值拼得出來——面積對不代表拼得成）。
再測⑬【進階】甲型 π×π 共 7 塊、乙型 π×1 共 17 塊、丙型 1×1 共 12 塊。拿掉哪一種紙板各一塊，剩下的可拼成大長方形？
逐一試：拿甲 → 6π²+17π+12 = (3π+4)(2π+3) ✓ 可分解 → (A) 甲型
對照：拿乙 → 7π²+16π+12（判別式 ＜ 0）✗；拿丙 → 7π²+17π+11（判別式非完全平方）✗
「可拼成」＝「可分解」。逐選項扣一塊、試分解，只有一組過。
再測⑭【進階】正整數 a、b 滿足 a²+a−12 = b 且 b ＜ 70，數對 (a,b) 共幾組？
(a+4)(a−3) = b → b 為正 → a ≥ 4。逐列：4→8、5→18、6→30、7→44、8→60 ✓；9→78 ✗ → 5 組
再測⑮ 長方形由 m(a+b+c) 與 n(a+b+c) 兩塊組成，關於 AB、AD 何者正確？(選項含 AB=m+n、AD=a+b+c…)
總面積 = m(a+b+c)+n(a+b+c) = (m+n)(a+b+c) → 一邊 AD = a+b+c、另一邊 AB = m+n（依原題選項選 AD = a+b+c）
提公因式的面積模型：公因式 (a+b+c) 就是共用的那條邊。
