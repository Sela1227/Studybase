國二上 · 第2章 平方根與畢氏定理

開根號這件事，一次弄懂

這章前半（平方根、根式）是一組新的運算工具；後半（畢氏定理）會反過來用到它——算三角形邊長時要開根號、還要化簡。先把工具練穩，後面才用得動。

前置快篩：平方與乘法公式、質因數分解、分數運算、簡單不等式與聯立方程式畢氏會用到平方根，故排在根式之後預計 40 分鐘／節
平方根 · 意義

平方根就是「反過來問」

平方是「一個數乘自己」；平方根是把這件事倒過來問。

32 = 9。反過來問：什麼數平方會等於 9？ 有兩個：3 和 −3（因為 32=9、(−3)2=9）。所以「9 的平方根」是 ±3。

根號 √ 表示「非負」的平方根（算術平方根）：√9 = 3、√0 = 0
完整規則：正數有兩個平方根，一正一負；0 只有一個平方根，就是 0；負數在實數範圍內沒有平方根。根號 √ 取的永遠是「非負」那一個（所以不會是負的）。
例：25 的平方根是多少？√25 呢？
25 的平方根 = ±5；√25 = 5（根號取非負）
「…的平方根」可能有兩個（±）；「√…」只有一個（非負）。
括號很重要（超常錯）：(−3)2 = 9，但 −32 = −9。沒有括號時，要先算平方、再加前面的負號：−32 = −(32) = −9。
平方根 · 估算

不是整數的平方根，落在哪裡

有些數開根號剛好是整數，有些不是。不是的，先夾出範圍，再估到小數。

完全平方數：開根號剛好是整數的數 —— 0, 1, 4, 9, 16, 25, 36, 49, 64, 81, 100…（02~102）。常用的從 12 開始背，但別忘了 0 也是。

① 夾出整數範圍：√10
9 < 10 < 16，即 32 < 10 < 42
所以 3 < √10 < 4
② 靠近哪個整數？（用中點判定）
中點 3.5，算 3.52 = 12.25
因為 10 < 12.25，所以 √10 < 3.5 → 靠近 3
不能只用「10 比較靠近 9」來猜——平方不是等距的。比中點的平方最可靠。
③ 估到十分位：√10
3.12 = 9.61，3.22 = 10.24
所以 3.1 < √10 < 3.2。要四捨五入，就比分界點 3.15：3.152 = 9.9225 ＜ 10 → √10 ＞ 3.15
→ 取到十分位 √10 ≈ 3.2
四捨五入不是「感覺比較近」，是跟分界點的平方比大小。百分位同理：3.16²=9.9856＜10、分界點 3.165²=10.017225＞10 → 3.16＜√10＜3.165 → 取到百分位 ≈ 3.16。
背熟 1~15 的平方（1,4,9,…,225），夾範圍會快很多。
2-1 · 整數條件與範圍（實戰）

什麼時候 √ 會開出整數？——質因數說了算

這幾種題型在你的考卷出現過。心法一句：√N 是整數 ⇔ N 的每個質因數都是偶數次方。缺什麼，就補什麼。

對正整數 N：√N 為正整數 ⇔ N 質因數分解後，每個指數都是偶數
教學群一 · 整數條件與完全平方數
例①【核心必會】√(180a)、√(180/b)、√(180+c)、√(180−d) 都是正整數，a、b、c、d 取最小正整數
先分解：180 = 22 × 32 × 5　（5 是奇數次方，就差它）
√(180a)：補一個 5 → a = 5（180×5 = 900 = 302）
√(180/b)：b 為正整數、且 180/b 要仍是正整數（b 是 180 的因數）→ 把 5 除掉 → b = 5（180÷5 = 36 = 62）
√(180+c)：找 180 之後最近的完全平方數 142=196 → c = 16
√(180−d)：找 180 之前最近的 132=169 → d = 11
乘除用「質因數補偶」；加減用「夾最近的完全平方數」（√180≈13.4，往上取 14²、往下取 13²）。兩套工具，看題目用哪套。
例②【進階】√(45a) 為正整數，且 10 ＜ a ＜ 100，這樣的 a 有幾個？
45 = 32 × 5 → a 必須是 5 × (完全平方數) = 5k2（k 為正整數）
10 ＜ 5k2 ＜ 100 → 除以 5：2 ＜ k2 ＜ 20 → 完全平方數只有 4、9、16
→ a = 20、45、80 → 3 個
a 不是只有一個——先寫出 a 的「形狀」（5k²），再用範圍篩 k。列出來逐一檢查，不會多也不會漏。
教學群二 · 根號範圍與面積應用
例③【核心必會】√x ＜ 5 的正整數 x 有幾個？√(3x) ≤ 9 呢？
兩邊平方：x ＜ 25 → x = 1～24 → 24 個
3x ≤ 81 → x ≤ 27 → 27 個
兩邊皆為非負數時，可以平方且不改變不等號方向。固定四步：① 確認根號內有意義 ② 確認另一邊非負 ③ 兩邊平方 ④ 按「正整數」條件計數。x＜25 的正整數是 1～24，別把 25 算進去、也別答成 25 個。
例④【進階】√(652 − 252) = ?
根號裡先用平方差：652−252 = (65+25)(65−25) = 90 × 40 = 3600
= √3600 = 60
√(a²−b²) 不等於 a−b（65−25=40 ≠ 60）！根號裡是整團的，要先把裡面算完或分解完才能開。三個平方相減也一樣：一步一步用平方差，不能亂消。
例⑤【進階】正方形面積是 2x+y，邊長怎麼寫？
邊長 = √(面積) = √(2x+y)（整個式子都在根號裡）
面積↔邊長的橋就是 √ 與平方。反過來：已知邊長是 4，面積就是 16——列成方程式就能解出裡面的 x、y（見再測）。
例⑥【核心必會】比例反推面積：正方形土地中，草地占全部的 3/5，草地面積 30 m²，求土地邊長介於哪兩個整數之間
先反推總面積：30 ÷ (3/5) = 30 × 5/3 = 50 m²
邊長 = √50；夾範圍：72 = 49 ＜ 50 ＜ 64 = 82 → 7 ＜ 邊長 ＜ 8
三步串起來：比例反推總面積 → 邊長 = √面積 → 用完全平方數夾範圍。題目不一定直接給總面積，先把「全部」找回來。
根號的紅線：√(A+B) ≠ √A + √B、√(A−B) ≠ √A − √B——根號可以拆乘除（2-2 學過），不能拆加減。根號裡有加減，先把裡面整團算完或分解完（像例④的兩次提公因式），才能開根號。
這課的三套工具：① 整數條件 → 質因數補偶　② 個數問題 → 寫出形狀再用範圍篩　③ 根號裡的運算 → 先算完（或分解完）再開，√(a²−b²) ≠ a−b。

根式 · 化簡

把藏在根號裡的完全平方「開出來」

根號裡如果有完全平方數的因數（4、9、16…），可以把它開出來放到根號外。

√(a2b) = a√b　(a ≥ 0，b ≥ 0)
一個重要觀念：一個數平方後再開根號，結果一定取非負值。例如 √((−3)2) = √9 = 3，不是 −3。（更正式寫成 √(a2) = |a|。）
例：化簡 √12
√12 = √(4 × 3) = √4 × √3 = 2√3
把 12 拆成「最大的完全平方因數 × 剩下的」：12 = 4 × 3。
例：化簡 √72
√72 = √(36 × 2) = 6√2
常見錯誤：√12 拆成 √4 + √8。根號裡是「相乘」才能拆，相加不行。
根式 · 加減乘除

加減看同類（先化到最簡），乘除合進根號

加減跟合併同類項一樣；但要先化到最簡才判斷同不同類。乘除則合進同一個根號。

先把每個根式化到最簡，再看根號內是否相同
例：√12 + √27（表面不同，其實同類）
√12 = 2√3，√27 = 3√3
2√3 + 3√3 = 5√3
不能只看原本根號內不同就說不能加——先各自化簡，這裡化簡後都是 √3，就能合併。
同類方根加減：2√3 + 5√3 = 7√3　（係數相加，√3 不變）
乘法：√a × √b = √(ab)　(a ≥ 0，b ≥ 0)
除法：√a ÷ √b = √(a/b)　(a ≥ 0，b > 0)
例：√2 × √8　；　√48 ÷ √3
√2 × √8 = √16 = 4
√48 ÷ √3 = √(48/3) = √16 = 4
常見錯誤：2√3 + 5√3 算成 7√6。根號不變，只有前面係數相加。
根式 · 有理化

分母有根號？上下同乘把它變整數

習慣上不讓分母留根號。上下同乘那個根號，分母就變整數了。

1/√a = √a / a　(a > 0)
適用範圍：a 要大於 0（a=0 分母為 0、a<0 沒有實數根）。本節先處理分母只有一個根式的情況；像 1/(1+√2) 這種分母有加減的，要用「共軛式」，之後才教。
例：1/√2　；　3/√5
1/√2 = √2 / (√2·√2) = √2 / 2
3/√5 = 3√5 / 5
上下同乘「同一個」根號（等於乘 1，值不變），分母就沒有根號了。
2-2 · 實戰題型

四種考卷上的樣子：最簡根式・小數部分・方程式・巧算

這幾種題型在你的考卷出現過。共通心法：先認出結構，再選方法。

題型一 · 什麼才是「最簡根式」
最簡根式三條件：① 根號內沒有平方因數　② 根號內沒有分數　③ 分母沒有根號
例①【核心必會】√20、√(2/3)、√10/2，哪個是最簡根式？
√20 = 2√5 → 根號內有平方因數 4 ✗
√(2/3) → 根號內有分數 ✗（化簡後 = √6/3 才是最簡）
√102 → 三條件都過 ✓ 最簡根式
判斷流程固定三步：先拆平方因數 → 檢查根號內分數 → 檢查分母根號。只想「能不能再開」會漏掉後兩條——√(2/5) 開不動，但它不是最簡。
題型二 · 根式的整數部分與小數部分
N = 整數部分 + 小數部分 a，其中 0 ≤ a ＜ 1
例②【核心必會】√5 的小數部分為 a（√5 = 2 + a），求 √20 的小數部分
√20 = 2√5 = 2(2+a) = 4 + 2a
檢查 2a 有沒有超過 1：√5 ＜ 2.25（2.25²=5.0625）→ a ＜ 0.25 → 2a ＜ 0.5 ＜ 1 ✓
→ 小數部分 = 2a（整數部分 4）
例③【進階】√7 = 2 + a，求 √28 的小數部分（會進位的情況）
√28 = 2√7 = 4 + 2a；但 2.5 ＜ √7 ＜ 3 → 0.5 ＜ a ＜ 1 → 1 ＜ 2a ＜ 2
2a 已經超過 1，要把整數 1 撥給整數部分：√28 = 5 + (2a−1)
→ 小數部分 = 2a − 1（整數部分 5）
小數部分不能只把含 a 的部分照抄——一定要檢查它是否 ≥ 1。超過就減 1 撥過去。這是本題型的唯一陷阱。
題型三 · 根式係數的一次方程式
例④【核心必會】2√5 · x − 3 = 7，求 x
① 移項：2√5 x = 10　② 除以係數：x = 10/(2√5) = 5/√5
③ 有理化：x = 5√5/5 = √5　④ 驗算：2√5·√5 = 10 ✓
固定四步：移項 → 除以根式係數 → 有理化 → 約分。注意題目是 (3√6)·x 這種「係數含根號」，不是 √(6x)——看清楚 x 在不在根號裡。
題型四 · 兩層乘法公式巧算
例⑤【進階】12 × √(11×9+1) + 1 = a²，a 為正整數，求 a
第一層（根號內）：11×9+1 = (10+1)(10−1)+1 = 10²−1+1 = 10² → 根號開出 10
原式 = 12×10 + 1 = 121。停！重新看整體：121 = (11+1)(11−1)+1 = 11²−1+1 = 11²
a² = 11²，a 為正整數 → a = 11
關鍵提醒：一個局部化簡完之後，把結果放回原式、重新觀察整體是否又是乘法公式。只做第一層就停，會答成 10。另外「a 為正整數」這句話決定了不取 −11——題目的每句話都有用。
這課四個開關：① 最簡＝三條件都過　② 小數部分要檢查進位　③ 根式係數方程式走四步　④ 化簡完一層，整體再看一次。
2-2 · 實戰二

估算與小數部分：不用算出精確小數

題型五 · 根式近似與比例比較
流程：夾根號範圍 → 換成比例的小數範圍 → 比較選項
例①【核心必會】1+√2 最接近哪個？(甲) 7/3　(乙) 12/5　(丙) 5/2
1.4² = 1.96 ＜ 2 ＜ 2.1025 = 1.45² → 1.4 ＜ √2 ＜ 1.45 → 2.4 ＜ 1+√2 ＜ 2.45
選項化小數：7/3 ≈ 2.33、12/5 = 2.4、5/2 = 2.5 → 最接近 12/5
整題不需要背 √2 = 1.414——用題目給的（或自夾的）平方範圍把根式關進區間，再把選項化成小數來比。
題型六 · 減式的整數與小數部分
小數部分 = 原數 − 整數部分（一定滿足 0 ≤ 小數部分 ＜ 1）
例②【核心必會】求 5 − √3 的整數部分與小數部分
1 ＜ √3 ＜ 2 → 減完方向會反：3 ＜ 5−√3 ＜ 4 → 整數部分 3
小數部分 = (5−√3) − 3 = 2 − √3
「減 √」的題先夾出整體範圍（注意不等號方向），整數部分出來後，小數部分永遠 = 原數 − 整數部分——它可以長得像 2−√3 這種式子，只要值在 0 和 1 之間就對。
題型七 · 小數部分的倒數：乘共軛
例③【核心必會】√3 的小數部分為 a，求 1/a
1 ＜ √3 ＜ 2 → a = √3 − 1
1/a = 1/(√3−1)，分母分子同乘共軛 (√3+1)：= (√3+1)/(3−1) = √3+12
分母長成 √n − k 或 √n + k，優先乘共軛（2-2 有理化那課的平方差應用）。
題型八 · [√k] 的分段計數
[√k] = m 發生在 m² ≤ k ＜ (m+1)²——一段一段算，不要逐項慢數
例④【進階】[√1]+[√2]+⋯+[√8] = ?
k 的範圍[√k]個數貢獻
1 ≤ k ≤ 3133
4 ≤ k ≤ 82510
總和 = 3 + 10 = 13
每一段的個數 = (m+1)² − m² = 2m+1（3、5、7、…）。反過來「總和 = 34 求 n」也是列這張表累積到 34（見再測）——答案是 n，不是把 34 抄回去。
2-2 · 實戰三

對稱與巧算：先看結構，再動手

題型九 · 共軛對稱式：先求 x+y 與 xy
例①【核心必會】x = (√7+√5)/2、y = (√7−√5)/2，求 x+y、xy、x²+y²
x+y = √7（√5 消掉）；xy = (7−5)/4 = 1/2（平方差）
x²+y² = (x+y)² − 2xy = 7 − 1 = 6
看到「一加一減」的共軛形式，先求 x+y 與 xy，其他全部用第1章對稱式改寫——各自平方硬展開又慢又容易錯。
題型十 · 帶分數根式的完全平方辨識
例②【進階】√(3 116) = ?
化假分數：= √(49/16)　（3×16+1 = 49，正好是 7²！）
= 7/4
n + 1/m² 型的帶分數，先算「n×m²+1 是不是完全平方數」——是的話整個根號直接開出來。
題型十一 · 根式係數聯立：對稱就「加」和「減」
例③【進階】(√3+√2)x + (√3−√2)y = 3√3+√2；(√3−√2)x + (√3+√2)y = 3√3−√2
兩式相加：2√3(x+y) = 6√3 → x+y = 3
兩式相減：2√2(x−y) = 2√2 → x−y = 1 → x = 2、y = 1
係數是「一加一減」的對稱結構時，加減會讓一半的根式直接消失——不要一開始就用一般消去法展開大量根式。
題型十二 · 有理化＋連鎖消去
例④【進階】1/(1+√3) + 1/(√3+√5) + 1/(√5+√7) = ?
每項乘共軛：1/(√a+√b) = (√b−√a)/(b−a) = (√b−√a)/2（相鄰奇數差 2）
= (√3−1)/2 + (√5−√3)/2 + (√7−√5)/2 → 中間全消 = (√7 − 1)/2
有理化把每一項變成「後減前」，整串就連鎖消去只剩頭尾——跟第1章的連乘消去是同一個精神。

畢氏定理 · 意義

兩股平方和 = 斜邊平方

這是直角三角形專屬的關係。公式裡的「平方」其實就是「邊上正方形的面積」。

圖 · 面積
三邊各作一個正方形。兩個小正方形（a2、b2）面積相加，剛好等於斜邊上大正方形（c2）的面積。
代數
a2 + b2 = c2
白話

a、b 是夾著直角的兩「股」；c 是對著直角、最長的「斜邊」。兩股各自平方加起來，等於斜邊的平方。

a2 + b2 = c2　（c 為斜邊）
最常錯：把斜邊 c 擺錯。c 一定是「對著直角、最長」那條。
畢氏定理 · 求邊長

知道兩邊，開根號求第三邊

這裡就用到 2-1、2-2 的開根號與化簡了——邊長不一定是整數。

例：兩股 3、4，求斜邊 c
c2 = 9 + 16 = 25 → c = √25 = 5
例：斜邊 13、一股 5，求另一股
b2 = 169 − 25 = 144 → b = √144 = 12
求股是「斜邊平方 − 股平方」，再開根號。
例（答案是根式）：等腰直角三角形兩股都是 6，求斜邊
c2 = 62 + 62 = 72
c = √72 = 6√2
這題完整串起來：畢氏 → 開根號 → 根式化簡（√72=6√2）。邊長不一定是整數。
有些邊長不能化簡，例如 √(52+72) = √74（74 沒有完全平方因數），答案就寫 √74。
常見錯誤：求「股」時用相加。求股是斜邊平方減股平方。
畢氏定理 · 逆定理與應用

反過來判斷直角，並用在生活裡

畢氏定理反過來也成立，可以用三邊長判斷是不是直角三角形。

若「最長邊2 = 另兩邊平方和」，則為直角三角形
例：三邊 6、8、10，是直角三角形嗎？
62 + 82 = 36 + 64 = 100 = 102 ✓ → 是
應用①：長 12 公尺、寬 5 公尺的長方形場地，從一角走到對角，最短距離多少？
對角線 = √(122 + 52) = √(144+25) = √169 = 13 公尺
長方形對角線把它切成直角三角形，長和寬就是兩股。要先判斷「求的是斜邊」。
應用②：10 公尺梯子靠牆，底部離牆 6 公尺，梯頂多高？
高 = √(102 − 62) = √(100−36) = √64 = 8 公尺
這裡梯子是斜邊，求的是「股」，所以用相減。判斷「求斜邊還是求股」是關鍵。
2-3 · 實戰一

圖裡沒有直角三角形？自己補一個

考卷上的畢氏題常把直角三角形「藏」在複合圖形裡。這課的流程適用所有這類題。

流程：找直角 → 標水平差與垂直差 → 建直角三角形 → 套畢氏 → 回答題目真正所問
題型一 · 補輔助線與長度差
例①【核心必會】L 形：外框寬 7、高 10；左側邊長 6、底邊長 4，求斜邊 BC
垂直差 = 整體高 − 局部：10 − 6 = 4；水平差 = 7 − 4 = 3
BC = √(4² + 3²) = √25 = 5
口訣：缺的直角邊，常是「整體長度 − 局部長度」。過缺口的頂點畫水平、垂直輔助線，直角三角形就出現了。
題型二 · 區域面積先還原完整正方形
例②【核心必會】兩正方形部分重疊成三區，面積 55、9、91，求圖中直角三角形的另一股
第一個正方形 = 55 + 9 = 64 → 邊長 8；第二個 = 9 + 91 = 100 → 邊長 10
斜邊 10、一股 8 → 另一股 = √(100−64) = 6
流程：區域相加 → 還原完整正方形 → 開根號得邊長 → 畢氏。不要從 55、9、91 直接猜邊長。
題型三 · 三邊已知，反求高與面積
例③【進階】三邊 13、14、15，求最長邊上的高與面積——經典雙畢氏
設高的垂足把 14 分成 x 與 14−x：13²−x² = 15²−(14−x)²（兩邊都等於 h²）
169−x² = 225−196+28x−x² → x = 5 → h² = 169−25 = 144 → h = 12
題目問面積：= ½ × 14 × 12 = 84
答案對象檢查：算完先問「我現在手上的是 x、高、還是面積？題目要的是哪個？」求出 h=12 就停筆，是這類題最冤的失分。
題型四 · 用三角形面積直接算長方形面積
例④【核心必會】長方形 ABCD 中，E 在 AB 上，DE=9、CE=12、∠DEC=90°，求長方形面積
DC = √(9²+12²) = 15；△DEC 面積 = ½×9×12 = 54
△DEC 與長方形同底 DC、同高（E 到 DC 的距離＝長方形的高）→ 長方形面積 = 2 × 54 = 108
三角形＝同底同高長方形的一半——反過來，長方形＝三角形的兩倍。不必真的算出高（54×2 比 先求高 7.2 再乘 15 快得多）。
2-3 · 實戰二

方格紙、路線圖、面積鏈：畢氏的三張臉

題型五 · 方格紙上的格點距離
斜線長度² = (水平格數)² + (垂直格數)²
例①【核心必會】格點 A 到 B：往右 2 格、往上 3 格，AB = ?
AB² = 2²+3² = 13 → AB = √13（格）
方格紙自帶直角——水平和垂直的格數就是兩股，數格子就好，不用另外找直角。
題型六 · 路線問題（畢氏之後還有下一步）
例②【核心必會】原路兩段互相垂直，長 60、80 公尺；直路 = ? 若原本走直路加前段共 100 m 花 10 分鐘，改繞垂直兩段多花幾分鐘？
直路 = √(60²+80²) = 100 m
路線距離時間
原路線100 m10 分
改道後140 m10 × 140/100 = 14 分
→ 多花 4 分鐘（要提早 4 分鐘出門）
速度不變 → 時間比 = 路程比。畢氏算完距離只是半題——把翻譯表填完，回答題目真正問的（幾點出門）。
題型七 · 面積形式的畢氏定理（面積鏈）
直角三角形：斜邊上的正方形面積 = 兩股上的正方形面積之和
例③【進階】三個直角三角形串起來的正方形塔，為什麼最大的 = 最小四個之和？
第一個三角形：戊 = 甲 + 乙；第二個：己 = 丙 + 丁
第三個三角形的兩股正是戊、己的邊 → 庚 = 戊 + 己 = 甲+乙+丙+丁
畢氏定理不只算邊長——它本身就是「面積的等式」，可以一層一層代入串接。寫證明時每一步標明用了哪個三角形。
2-3 · 實戰三

中心距離、摺紙、長方形定理

題型八 · 相鄰正方形的中心距離
正方形中心到每一邊的距離 = 邊長的一半
例①【核心必會】邊長 2 與 6 的正方形底部對齊併排，求兩中心距離
水平距離 = 2/2 + 6/2 = 4；垂直距離 = 6/2 − 2/2 = 2
距離 = √(4²+2²) = √20 = 2√5
中心不在格線上沒關係——一樣是「水平差、垂直差」建直角三角形，只是差要用半邊長組出來。
題型九 · 摺紙＝垂直平分線
摺疊使 B 落在 E → 摺痕是 BE 的垂直平分線 → 摺痕上任一點到 B、E 等距
例②【核心必會】用這個性質的固定三步
① 摺痕過 A → AB = AE（先把「不動的長度」找出來）
② 用畢氏在直角三角形裡解出未知邊（常是 AD 或 DE）
③ 摺痕另一端 F 也有 FB = FE → 設 x 列方程式 → 最後用畢氏求摺痕長
摺紙題的全部資訊就是「等距」兩個字——摺痕兩端各寫一條等距，配畢氏就解完（完整數字流程見再測⑬）。
題型十 · 長方形內點定理（英國國旗定理）
長方形內任一點 P：PA² + PC² = PB² + PD²（對角兩組的平方和相等）
例③【核心必會】PA=3、PB=5、PC=7，求 PD
9 + 49 = 25 + PD² → PD² = 33 → PD = √33
記法：把 P 向兩邊作垂線，四段距離兩兩重組，兩組對角都等於同樣的四個平方和。列式時對角配對別配錯（A、C 一組；B、D 一組）。
題型十一 · 面積連鎖：邊長還是面積？
例④【進階】正方形塔：最大正方形邊長 5，左斜邊上的正方形 = 2²+3² = 13，求右邊正方形的邊長
面積關係：13 + (右) = 5² = 25 → 右 = 12
題目問邊長 → √12 = 2√3
畢氏定理裡的平方是「面積」；題目若問邊長，最後還要開根號。答案寫 12 就是把面積當邊長——答案對象檢查再次上場。
題型十二 · 對角線平行 → 等高轉移面積
例⑤【進階】兩正方形方向相同時，BD ∥ CF，怎麼用？
C、F 到直線 BD 的距離相同（平行線間距離處處相等）→ △BDF 與 △BDC 同底 BD、等高 → 面積相等
而 △BDC 是大正方形的一半 → [△BDF] = 大正方形面積 ÷ 2
看到「頂點在一條平行線上滑動」就想等高轉移——比硬做大面積扣小面積快非常多（見再測⑭）。

座標距離與整數直角三角形

題型十三 · 等距點：距離「平方」相等就好
例①【核心必會】A 在直線 x=2 上，到 (0,0) 與 (4,4) 等距，求 A
設 A = (2, t)。等距 → 距離平方相等（不用開根號）：2²+t² = (2−4)²+(t−4)²
4+t² = 4+t²−8t+16 → 8t = 16 → t = 2 → A = (2, 2)
等距問題直接令「平方相等」，t² 會自己消掉，剩一次方程式。
題型十四 · 距離平方的重組
例②【進階】A(0,a)、B(−b,0)、C(0,−c)、D(d,0)，已知 AB²=20、CD²=44，求 √(AD²+BC²)
AD²+BC² = (a²+d²)+(b²+c²) = (a²+b²)+(c²+d²) = 20+44 = 64
→ √64 = 8
四個平方自由重組——不用（也不能）求出各邊。看到「平方和」先想「能不能換組」。
題型十五 · 整數直角三角形：平方差配對
例③【進階】一股 5，另一股與斜邊都是整數，求周長
c² − b² = 25 → (c−b)(c+b) = 25 → 正因數配對只有 1×25（5×5 給 b=0 捨去）
c−b=1、c+b=25 → c=13、b=12 → 周長 = 5+12+13 = 30
畢氏＋第1章平方差＋因數配對三合一。配對照固定流程：列配對 → 解 → 檢查正整數。
題型十六 · 追趕與可達：位置 → 距離 → 比較
先算目前位置 → 畢氏算直線距離 → 比較「剩餘時間 × 速度」夠不夠走
例④【核心必會】甲向東 2 m/s、乙向北 3 m/s，5 分鐘後乙抵達目標。甲還有 10 分鐘，趕得到嗎？
5 分鐘後：甲在東 600 m、目標在北 900 m → 距離 = √(600²+900²) = 300√13 ≈ 1082 m
甲剩餘可走 2×600 = 1200 m ＞ 1082 → 趕得到
比較時可以平方：(300√13)² = 1,170,000 與 1200² = 1,440,000——避免小數。
