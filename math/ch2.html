開根號這件事，一次弄懂

這章前半（平方根、根式）是一組新的運算工具；後半（畢氏定理）會反過來用到它——算三角形邊長時要開根號。跟第1章一樣，先把工具練穩，後面才用得動。

前置：第1章（平方的概念）畢氏會用到平方根，故排在根式之後預計 40 分／節
平方根 · 意義

平方根就是「反過來問」

平方是「一個數乘自己」；平方根是把這件事倒過來問。

32 = 9。反過來問：什麼數平方會等於 9？ 答案有兩個：3 和 −3（因為 32=9、(−3)2=9）。所以「9 的平方根」是 ±3。

根號 √ 只取正的那一個：√9 = 3

一個正數有兩個平方根（一正一負），但根號 √ 這個符號只代表正的那個（叫算術平方根）。所以 √9 = 3，而不是 ±3。

例：25 的平方根是多少？√25 呢？
25 的平方根 = ±5（52=25、(−5)2=25）
√25 = 5（根號只取正）
「…的平方根」是兩個（±）；「√…」只有一個（正）。這兩個問法不一樣。
最常錯：把 √9 寫成 ±3。看到根號 √ 就只取正根；只有「9 的平方根」才是 ±3。
平方根 · 估算

不是整數的平方根，落在哪兩個整數之間

有些數開根號剛好是整數，有些不是。不是的，就估它在哪兩個整數中間。

完全平方數：開根號剛好是整數的數 —— 1, 4, 9, 16, 25, 36, 49, 64, 81, 100…（就是 12~102）。

例：√10 在哪兩個整數之間？
因為 32=9 < 10 < 16=42
所以 3 < √10 < 4，而且比較靠近 3
找出 10 夾在哪兩個完全平方數之間（9 和 16），它的根號就在對應的兩個整數（3 和 4）之間。
例：√50 在哪兩個整數之間？
72=49 < 50 < 64=82 → 7 < √50 < 8，靠近 7
把 1~15 的平方背熟（1,4,9,16,25,36,49,64,81,100,121,144,169,196,225），估算會快很多。

根式 · 化簡

把藏在根號裡的完全平方「開出來」

根號裡如果有完全平方數的因數（4、9、16…），可以把它開出來放到根號外。

√(a2b) = a√b　(a ≥ 0)
例：化簡 √12
√12 = √(4 × 3) = √4 × √3 = 2√3
把 12 拆成「最大的完全平方因數 × 剩下的」：12 = 4 × 3，4 開出來變 2。
例：化簡 √72
√72 = √(36 × 2) = 6√2
36 是 72 裡最大的完全平方因數，開出來是 6。
常見錯誤：√12 拆成 √4 + √8。根號裡是「相乘」才能拆開，相加不行。
根式 · 四則

加減看「同不同類」，乘除直接進根號

加減跟合併同類項一樣；乘除則可以合進同一個根號。

同類方根才能加減：2√3 + 5√3 = 7√3　（係數相加，√3 不變）
乘除進根號：√a × √b = √(ab)
例：2√3 + 5√3 − √3
= (2 + 5 − 1)√3 = 6√3
根號裡都是 3，是同類方根，就像同類項一樣把係數加起來，√3 不動。
例：√2 × √8
= √(2 × 8) = √16 = 4
常見錯誤：2√3 + 5√3 算成 7√6（把根號裡也加了）。根號不變，只有前面係數相加。
根式 · 有理化

分母有根號？上下同乘把它變整數

習慣上不讓分母留根號。上下同乘那個根號，分母就變整數了。

1/√a = √a / a
例：把 1/√2 有理化
= (1 × √2) / (√2 × √2) = √2 / 2
上下同乘 √2。分母 √2×√2 = 2，就不再有根號了。
例：3/√5
= 3√5 / (√5×√5) = 3√5 / 5
提醒：上下要乘「同一個」根號，值才不變（等於乘 1）。只乘分母會改變大小。

畢氏定理 · 意義

直角三角形：兩股平方和 = 斜邊平方

這是直角三角形專屬的關係。先認清楚哪條是「股」、哪條是「斜邊」。

圖
a、b 是夾直角的兩股；c 是對著直角的斜邊（最長）
代數
a2 + b2 = c2
白話

兩條夾著直角的邊（股），各自平方加起來，剛好等於對著直角那條最長邊（斜邊）的平方。

a2 + b2 = c2　（c 為斜邊）
最常錯：把斜邊 c 擺錯。c 一定是「對著直角、最長」那條。位置擺錯，整條式子就錯。
畢氏定理 · 求邊長

知道兩邊，開根號求第三邊

這裡就用到 2-1、2-2 的開根號了。

例：兩股 3、4，求斜邊 c
c2 = 32 + 42 = 9 + 16 = 25
c = √25 = 5
求斜邊：兩股平方相加，再開根號。
例：斜邊 13、一股 5，求另一股 b
b2 = 132 − 52 = 169 − 25 = 144
b = √144 = 12
求股：是「斜邊平方 − 已知股平方」，再開根號。
常見整數組（背起來很省時）：(3,4,5)、(6,8,10)、(5,12,13)、(8,15,17)。
常見錯誤：求「股」時用相加。求股是斜邊平方減股平方，不是相加。
畢氏定理 · 逆定理與應用

反過來，也能用它判斷是不是直角

畢氏定理反過來也成立，可以用三邊長判斷一個三角形是不是直角三角形。

若最長邊2 = 另兩邊平方和，則為直角三角形
例：三邊 6、8、10，是直角三角形嗎？
最長邊 10：62 + 82 = 36 + 64 = 100 = 102 ✓
成立，所以是直角三角形。
例（應用）：一支梯子靠牆，底部離牆 3 公尺，梯頂高 4 公尺，梯子多長？
梯長2 = 32 + 42 = 25 → 梯長 = 5 公尺
牆與地面成直角，梯子就是斜邊。畢氏定理最常出現在這種「求直線距離」的情境。

觀念辨識

1. 直角三角形裡，斜邊是哪一條？
斜邊對著直角，也是最長的一條。
2. 兩股 6、8，斜邊是？
62+82=100，斜邊要再開根號 √100=10（100 是還沒開根號、14 是誤把邊長相加）。
3. 三邊 5、12、13 是直角三角形嗎？
25+144=169=13²，成立，是直角三角形。

基本計算

① 兩股 9、12，求斜邊
c=√(81+144)=√225=15
② 斜邊 17、一股 8，求另一股
b=√(289−64)=√225=15
求股用相減。
③ 三邊 7、24、25，是直角三角形嗎？
7²+24²=49+576=625=25² → 是
