3-1 · 三角形

內角和 180°；外角＝不相鄰兩內角的和

三角形內角和 = 180°　；　一個外角 = 與它不相鄰的兩內角之和
外角是誰：把一邊（BC）往外延長到 D，∠ACD（延長線與另一邊 CA 的夾角）就是 C 處的外角——它跟內角 ∠ACB 互補。
看圖記住外角
C 處的外角 = ∠A + ∠B（把 C 的內角補到 180° 剩下的，就是另外兩角的和）
兩個理由等價：外角＋∠C=180°，而 ∠A+∠B+∠C=180° → 外角=∠A+∠B。
例①【核心必會】兩內角為 50°、60°，求第三角與 50° 那頂點的外角
第三角 = 180 − 110 = 70°；50° 頂點的外角 = 180−50 = 130°（也 = 60+70 ✓）
例②【核心必會】某外角 115°，其中一個不相鄰內角 40°，求另一個
115 = 40 + ? → 75°
用「外角=遠處兩內角和」直接一步；不用先算 180−115。
3-1 · 多邊形

切成三角形數內角；外角和永遠 360°

n 邊形內角和 = (n−2) × 180°　；　外角和 = 360°（跟邊數無關）
為什麼是 (n−2)？
從一個頂點拉對角線，n 邊形被切成 (n−2) 個三角形，每個 180°
外角和 360° 有兩個看法：① 沿著多邊形走一圈，每個轉彎轉的就是外角，走回原點共轉了一整圈；② 把每個外角剪下來、頂點靠攏拼在一起，恰好拼滿一圈。
例①【核心必會】八邊形內角和？正五邊形每個內角？
(8−2)×180 = 1080°；正五邊形每內角 = (5−2)×180 ÷ 5 = 108°
例②【進階】內角和 1440° 的多邊形有幾邊？正 n 邊形每個外角 30°，n = ?
(n−2)×180 = 1440 → n−2 = 8 → n = 10
每外角 30° → n = 360 ÷ 30 = 12
正多邊形用「外角」常比內角快：每外角 = 360/n，一除就出來。

3-2 · 基本

只准用「沒有刻度的直尺」和圓規

尺規作圖的規則：直尺只能畫直線（不能量長度）、圓規只能畫圓弧與搬距離。

圓規的本事：把「相同的距離」搬到別的地方
作圖①：作一線段等於已知線段 AB
1. 畫一條射線，取端點 C　2. 圓規張開量 AB 的長　3. 以 C 為圓心畫弧，交射線於 D → CD = AB
作圖②：作一角等於已知角 ∠O
1. 以 O 為圓心畫弧，交兩邊於 A、B　2. 畫一條射線取端點 O′；用與步驟 1 相同的半徑、以 O′ 為圓心畫弧，交射線於 A′——這條弧要畫得夠長，因為 B′ 會落在它上面　3. 圓規量 AB 的距離，以 A′ 為圓心畫弧，交步驟 2 的弧於 B′　4. 連 O′B′ → ∠O′ = ∠O
背後原理是下一節的 SSS 全等：兩個三角形三邊對應相等，角就相等。尺規作圖不是魔術，每一步都有全等在撐。
3-2 · 兩大作圖

中垂線與角平分線：考最多的兩個

作圖③：線段 AB 的中垂線（垂直平分線）
1. 以 A、B 為圓心，取相同且大於 AB 一半的半徑，各畫一弧　2. 兩弧交於上下兩點　3. 連這兩點 → 就是 AB 的中垂線
半徑要「大於一半」兩弧才會相交；半徑要「相同」交點才會到 A、B 等距（3-4 的性質）。
作圖④：∠O 的角平分線
1. 以 O 為圓心畫弧，交兩邊於 A、B　2. 以 A、B 為圓心、相同半徑各畫一弧，交於 P　3. 連 OP → OP 平分 ∠O
作圖⑤：過線外一點 P 作垂線
1. 以 P 為圓心畫弧，交直線於兩點 A、B　2. 作 AB 的中垂線（作圖③）——它必過 P 且垂直
新作圖常是舊作圖的組合——垂線 = 「先造出一段 AB，再作它的中垂線」。

3-3 · 意義

全等＝疊起來完全重合

△ABC ≅ △DEF：對應頂點照順序寫——A↔D、B↔E、C↔F

全等的三角形，對應邊相等、對應角相等。記號 ≅ 裡的順序就是對應關係：AB 對 DE、∠B 對 ∠E。

例：△ABC ≅ △PQR，AB=5、∠C=70°，能知道什麼？
PQ = AB = 5　；　∠R = ∠C = 70°
找對應「看字母位置」：AB 是第 1、2 個字母 → 對 PQ；∠C 是第 3 個 → 對 ∠R。順序寫錯，整題跟著錯。
3-3 · 判別

五個夠用的組合，兩個著名的陷阱

條件內容
SSS三邊對應相等
SAS兩邊與夾角對應相等
ASA兩角與夾邊對應相等
AAS兩角與其中一角的對邊對應相等
RHS兩個都是直角三角形時：斜邊與一股對應相等（也叫 HL）
兩個不能用的：SSA（兩邊與「非夾角」）——同樣的資料可能拼出兩種不同的三角形；AAA（三角相等）——形狀相同但大小可以不同（那是相似，國三的事）。
RHS 為什麼可以？它看起來像 SSA（兩邊＋非夾角 90°），但直角是特例：斜邊固定時另一股只有一種拼法，所以成立——前提是兩個三角形都有直角，一般角度的 SSA 仍然不行。
例【核心必會】已知 AB=DE、∠B=∠E、BC=EF，全等嗎？用哪個條件？
∠B 夾在 AB 與 BC 之間、∠E 夾在 DE 與 EF 之間 → SAS ✓ 全等
判斷 SAS 的關鍵一問：「這個角是不是被那兩邊夾住？」不是夾角就掉進 SSA。

3-4 · 性質

中垂線：到兩端等距；角平分線：到兩邊等距

P 在 AB 的中垂線上 ⇔ PA = PB　；　P 在 ∠O 的角平分線上 ⇔ P 到兩邊的（垂直）距離相等
例①【核心必會】P 在 AB 的中垂線上，PA = 3x−2、PB = x+8，求 x
PA = PB → 3x−2 = x+8 → x = 5
看到「中垂線上的點」，反射動作就是寫「到兩端等距」——性質變方程式。
例②【進階】為什麼成立？（用全等說一次）
設中垂線交 AB 於 M。△PMA 與 △PMB：PM 共用、MA=MB（中點）、夾角都是 90° → SAS 全等 → PA=PB
3-3 的全等就是這章所有性質的引擎——性質不是背的，是全等推出來的。角平分線那條用 AAS（或 RHS）同理。
反過來也對（逆敘述）：PA=PB 的點必在中垂線上；到兩邊等距的點必在角平分線上。「找到兩村莊等距的水井位置」這類題就是在考逆敘述。

3-5 · 存在條件

任兩邊之和 大於 第三邊

三邊能組成三角形 ⇔ 任兩邊之和 ＞ 第三邊（檢查「兩小邊之和 ＞ 最大邊」即可）
例①【核心必會】3、5、x 能組成三角形，x 的範圍？整數 x 有幾個？
兩邊之差 ＜ x ＜ 兩邊之和 → 2 ＜ x ＜ 8
整數 x = 3、4、5、6、7 → 5 個
口訣「差 ＜ 第三邊 ＜ 和」。端點 2 和 8 不含（等於時三點共線、拉不起來）。
例②【核心必會】4、4、9 能組成三角形嗎？
兩小邊 4+4 = 8 ＜ 9 → 不能
只要檢查「兩小加起來夠不夠跨過最大」這一條就好。
3-5 · 邊角對照

大邊對大角、大角對大邊

同一個三角形內：邊越長，它對面的角越大（反之亦然）
例①【核心必會】三邊 5、7、9，哪個角最大？
最長邊 9 的對角最大（9 對面的那個角）
「對」= 面對面：邊 9 的對角是不碰到這條邊的那個頂點。
例②【進階】∠A=50°、∠B=60°，哪條邊最長？
∠C = 70° 最大 → 它的對邊 AB 最長
完整排序照角來：70°＞60°＞50° → 對邊 AB ＞ AC ＞ BC（∠B 對 AC、∠A 對 BC）
先把第三角算出來（3-1 回鍋），再用大角對大邊。角的對邊是「名字裡沒有它的那條」：∠C 的對邊是 AB。
只能在「同一個」三角形裡比。兩個不同三角形的邊角不能用這條互比。
