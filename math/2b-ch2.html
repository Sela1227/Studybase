國二下 · 第2章 函數

一台「輸入 x、輸出 y」的機器

函數是往後所有圖形章節的語言（國三的二次函數就建在這上面）。這章只有一節，量不大，但「每個 x 恰好對應一個 y」這句話要真的懂。

前置：一次式代入、座標平面預計 40 分鐘／節單節：2-1 函數與函數圖形
2-1 · 認識

每個 x，恰好對應一個 y

把函數想成一台機器：投入一個 x，一定吐出恰好一個 y。

y 是 x 的函數 ⇔ 每一個 x 值，都恰好對應一個 y 值
例：這些是函數嗎？
y = 2x + 1　→ 每個 x 算出一個 y ✓ 是函數
「y = x 的平方」→ 每個 x 有唯一的平方 ✓ 是函數（x=2 和 x=−2 都給 y=4 沒關係——不同的 x 可以對到同一個 y）
「y 的平方 = x」→ x=9 時 y 可以是 3 或 −3，一個 x 對到兩個 y ✗ 不是函數
方向是關鍵：管的是「一個 x 不能對多個 y」；反過來多個 x 對同一個 y 完全合法。
函數可以用式子（y=2x+1）、表格（x 和 y 的對照表）、圖形（下下課）三種面貌出現——同一台機器，三種說明書。
2-1 · 函數值

f(2) 的意思：把 2 投進機器

y = f(x)：f(2) 就是「x=2 時的 y 值」
例①【核心必會】f(x) = 3x − 2，求 f(2)、f(−1)
f(2) = 3×2 − 2 = 4　；　f(−1) = 3×(−1) − 2 = −5
f(−1) 的負號要整個代進去：3×(−1) 是 −3，不是 3−1。代負數時先加括號。
例②【核心必會】f(x) = 3x − 2，若 f(a) = 10，求 a
3a − 2 = 10 → a = 4
「f(a)=10」是反著問：輸出是 10，輸入是多少？——列一次方程式解回去。
f(2) 不是 f 乘以 2——f 是機器的名字，不是數。f(2) 整個是一個記號，讀作「f 在 2 的值」。

例②【核心必會】點 (2,3)、(3,4) 在 y = 2x−1 的圖形上嗎？
(2,3)：2×2−1 = 3 ✓ 在　；　(3,4)：2×3−1 = 5 ≠ 4 ✗ 不在
「在圖形上」＝代入後等式成立。不用畫圖，代一下就知道。
兩個特例：y = 3（常數函數）的圖形是水平線——每個 x 都輸出 3，是函數 ✓。而鉛直線 x = 2 上，x=2 對到無限多個 y——不是函數的圖形。

觀念辨識（答錯可再選）

1. 「一個 y 值被兩個不同的 x 對到」，y 還是 x 的函數嗎？
函數只管「一個 x 不能對多個 y」；多個 x 對同一個 y 合法（如 y=x²）。
再看一次，選出正確的。
2. f(x) = 5x + 1，f(3) 的意思是？
把 3 投入機器：5×3+1=16。f 不是數，不能相乘。
再看一次，選出正確的。
3. 下列哪條線不是函數的圖形？
x=2 這一個 x 對到無限多個 y → 不是函數。水平線 y=3 每個 x 都對到 3，是函數。
再看一次，選出正確的。

基本計算

① f(x) = −2x + 7，求 f(0) 與 f(3)
f(0) = 7；f(3) = −6+7 = 1
② 承①，f(a) = −1，求 a
−2a+7 = −1 → a = 4
③ 點 (−1, −3) 在 y = 2x − 1 的圖形上嗎？
2×(−1)−1 = −3 ✓ 在
④ 在紙上畫出 y = −x + 2 的圖形（描點法）
