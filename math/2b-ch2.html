國二下 · 第2章 函數

一台「輸入 x、輸出 y」的機器

函數是往後所有圖形章節的語言（國三的二次函數就建在這上面）。這章只有一節，量不大，但「每個 x 恰好對應一個 y」這句話要真的懂。

前置：代數式代值、一次方程式、負數運算、座標平面與有序數對預計 40 分鐘／節單節：2-1 函數與函數圖形
2-1 · 認識

每個 x，恰好對應一個 y

把函數想成一台機器：投入一個 x，一定吐出恰好一個 y。

y 是 x 的函數 ⇔ 在題目允許的範圍內，每一個 x 都恰好對應一個 y
例：這些是函數嗎？
y = 2x + 1　→ 每個 x 算出一個 y ✓ 是函數
「y = x 的平方」→ 每個 x 有唯一的平方 ✓ 是函數（x=2 和 x=−2 都給 y=4 沒關係——不同的 x 可以對到同一個 y）
「y 的平方 = x」→ x=9 時 y 可以是 3 或 −3，一個 x 對到兩個 y ✗ 不是函數
方向是關鍵：管的是「一個 x 不能對多個 y」；反過來多個 x 對同一個 y 完全合法。
「允許的範圍」很重要：像 y = 1/x，x = 0 不能代（分母不能為 0），但在 x ≠ 0 的範圍內，每個 x 仍恰好給一個 y——它還是函數。

函數可以用式子（y=2x+1）、表格（x 和 y 的對照表）、圖形（下下課）三種面貌出現——同一台機器，三種說明書。
2-1 · 函數值

f(2) 的意思：把 2 投進機器

y = f(x)：f(2) 就是「x=2 時的 y 值」
例①【核心必會】f(x) = 3x − 2，求 f(2)、f(−1)
f(2) = 3×2 − 2 = 4　；　f(−1) = 3×(−1) − 2 = −5
f(−1) 的負號要整個代進去：3×(−1) 是 −3，不是 3−1。代負數時先加括號。
例②【核心必會】f(x) = 3x − 2，若 f(a) = 10，求 a
3a − 2 = 10 → a = 4
「f(a)=10」是反著問：輸出是 10，輸入是多少？——列一次方程式解回去。
例③【進階】f(x) = 2x − 3，求 f(a+1)，並跟 f(a)+1 比較
把整個 a+1 代進 x 的位置：f(a+1) = 2(a+1) − 3 = 2a − 1
而 f(a) + 1 = (2a−3) + 1 = 2a − 2 → f(a+1) ≠ f(a) + 1
括號裡是什麼，就整團代進去。f(a+1) 是「先加 1 再進機器」；f(a)+1 是「先進機器再加 1」——順序不同、結果不同。
f(2) 不是 f 乘以 2——f 是機器的名字，不是數。f(2) 整個是一個記號，讀作「f 在 2 的值」。
2-1 · 函數圖形

把每一組 (x, y) 畫到座標平面上

函數圖形＝所有 (x, f(x)) 點的集合。

式子名稱圖形

y = b（即 a = 0）常數函數水平線
x = c不是 y 對 x 的函數鉛直線
例①【核心必會】畫 y = 2x − 1
x−1012
y−3−113
描四個點 → 它們在同一直線上 → 連成直線（兩端加箭頭表示持續延伸）
畫一次函數其實描兩點就夠（兩點決定一直線），多描一點當檢查。能連成直線是因為這是一次函數——不是所有函數的點都能拿直線連。
是否連線，看兩件事：① 函數類型——一次函數才是直線（像 y = x² 的點就不能用直線硬連）；② x 的取值範圍——若 x 只取指定的幾個值（例如只有整數），圖形就只有那幾個點，不連線。
例②【核心必會】點 (2,3)、(3,4) 在 y = 2x−1 的圖形上嗎？
(2,3)：2×2−1 = 3 ✓ 在　；　(3,4)：2×3−1 = 5 ≠ 4 ✗ 不在
「在圖形上」＝代入後等式成立。不用畫圖，代一下就知道。
兩個特例：y = 3（常數函數）的圖形是水平線——每個 x 都輸出 3，是函數 ✓。而鉛直線 x = 2 上，x=2 對到無限多個 y——不是函數的圖形。
鉛直線判別法：一刀切下去，看碰到幾次
在圖上任畫鉛直線（紅虛線）：每條至多交圖形一次 → 是函數圖形；有一條交兩次以上 → 不是
鉛直線 x = k 就是在問「x = k 對到幾個 y」——交兩點，就是一個 x 對到兩個 y。圓被切到上下兩點，所以不是。

觀念辨識（答錯可再選）

1. 「一個 y 值被兩個不同的 x 對到」，y 還是 x 的函數嗎？
函數只管「一個 x 不能對多個 y」；多個 x 對同一個 y 合法（如 y=x²）。
再看一次，選出正確的。
2. f(x) = 5x + 1，f(3) 的意思是？
把 3 投入機器：5×3+1=16。f 不是數，不能相乘。
再看一次，選出正確的。
3. 下列哪條線不是函數的圖形？
x=2 這一個 x 對到無限多個 y → 不是函數。水平線 y=3 每個 x 都對到 3，是函數。
再看一次，選出正確的。

基本計算

① f(x) = −2x + 7，求 f(0) 與 f(3)
f(0) = 7；f(3) = −6+7 = 1
② 承①，f(a) = −1，求 a
−2a+7 = −1 → a = 4
③ 點 (−1, −3) 在 y = 2x − 1 的圖形上嗎？
2×(−1)−1 = −3 ✓ 在
④ 在下方坐標紙畫出 y = −x + 2 的圖形（描點法）
描 (0,2)、(2,0)，連直線（再描 (1,1) 檢查共線）；兩端加箭頭。
往右走 1、往下走 1 的直線；跟 y=2x−1 比較斜的方向。因為是一次函數（a=−1≠0），才可以連成直線。
⑤【讀圖】某函數圖形上只有四個點：(−1,2)、(0,3)、(1,1)、(2,3)。(1) f(−1) = ?　(2) f(x)=3 時，x 可能是哪些？
(1) f(−1) = 2　(2) y=3 的點有 (0,3) 和 (2,3) → x = 0 或 2
一個 y 對到兩個 x 完全合法——這正是「多 x 對一 y 可以」的圖形版。
⑥【判斷】用鉛直線判別法：A 斜直線、B 圓、C 水平線，哪些是函數圖形？
A、C 是；B 不是（鉛直線會切到圓的上下兩點）。
⑦【表格描點】x = −2、−1、0、1、2，f(x) = 4、1、0、1、4。在紙上描出這五個點
描 (−2,4)(−1,1)(0,0)(1,1)(2,4)。只畫這五個點——題目沒給函數規則，不能自行連線。
（這五個點其實落在 y=x² 上——就算連，也不會是直線。國三會正式見面。）
