國二下的起點：找規律、用公式

這章主要用一次方程式、分數與指數運算；進階的「由總和反求項數」會接回國二上第4章的一元二次方程式，等比中項會用到第2章的平方根。學校有提前進度考，這章就是現在進行式：把「找規律 → 寫成公式 → 用公式算」這條路走熟，進度考直接受益。

前置：一次方程式、分數與指數運算（進階題用到平方根、一元二次）預計 40 分鐘／節1-1 等差數列 → 1-2 等差級數 → 1-3 等比數列
1-1 · 認識

每次都加同一個數，就是等差

數列＝按順序排好的一串數。第 1 個叫首項 a1，第 n 個叫第 n 項 an。

等差數列：後項 − 前項 ＝ 固定的數（公差 d）
例：3、7、11、15、19、…
7−3 = 11−7 = 15−11 = 4 → 是等差數列，公差 d = 4
檢查「是不是等差」就是把相鄰兩項相減，看差是否每一組都相同——只查一組不夠。
例：公差可以是負的、也可以是分數
20、17、14、11、…　→ d = −3（一直在變小）
1、32、2、52、…　→ d = 12
5、5、5、5、…　→ d = 0（公差可以是 0——每次「加 0」也是加同一個數）
常見錯：2、4、8、16、…（每次×2）不是等差——4−2=2 但 8−4=4，差不固定。它是 1-3 要學的「等比」數列。
1-1 · 一般項

an = a1 + (n−1)d：想去第 n 項，走 n−1 步

從首項出發，到第 n 項要「加 d」幾次？答案是 n−1 次——這就是整條公式。

an = a1 + (n − 1)d　（n = 1, 2, 3, …）
例①【核心必會】3、7、11、…的第 10 項
a1=3、d=4 → a10 = 3 + 9×4 = 39
是 (n−1)=9 步，不是 10 步——從第 1 項到第 10 項只走 9 步。這是本章第一大失分點。
例②【核心必會】已知 a3=11、a7=23，求公差與首項
從第 3 項到第 7 項走了 7−3 = 4 步：23 − 11 = 4d → d = 3
a1 = a3 − 2d = 11 − 6 = 5
兩項相減 = 步數 × d。不用把數列整串寫出來。
任意兩項通式：an = am + (n − m)d　（即 an − am = (n−m)d）
例②-2【核心必會】a5=12、a11=30，求公差
30 − 12 = (11−5)d → 6d = 18 → d = 3
通式讓「已知任意兩項」一步到位，不必每次先倒推首項。
例③【進階】100 和 98，哪個在數列 2、5、8、11、… 裡？
an = 2 + (n−1)·3 = 3n − 1
3n−1 = 100 → n = 1013，不是正整數 → 100 不在
3n−1 = 98 → n = 33 ✓ → 98 是第 33 項
「在不在數列裡」= 解出來的 n 是不是正整數。這招在進度考很常見。
項數公式（d ≠ 0 時）：由一般項反解得 n = (an − a1) ÷ d ＋ 1。算出來的 n 必須是正整數，否則該數不是數列中的項。101/3 這種分數就是「不在」的訊號。
1-1 · 中項與應用

等差中項：中間 = 兩邊的平均

a、b、c 成等差 ⇔ 2b = a + c（b 是 a、c 的平均）
例①【核心必會】5、x、17 成等差數列，求 x
2x = 5 + 17 → x = 11
中間項到兩邊「一減一加」同一個 d，所以正好是平均。
例②【進階】三個數成等差，和為 24，怎麼設最好算？
設三數為 a−d、a、a+d → 相加 = 3a = 24 → a = 8
→ 中間的數一定是 8，再依其他條件解 d
對稱設法讓「和」直接消掉 d——比設 a、a+d、a+2d 少算很多。
例③【進階】在 4 與 24 之間插入 4 個數，使六個數成等差數列
共 4+2 = 6 項 → 從 4 到 24 走了 5 步 → d = (24−4) ÷ 5 = 4
數列：4、8、12、16、20、24
「插入 k 個中項」→ 總項數 k+2、間隔 k+1 個。先數清楚走幾步，再除。
1-1 三件武器：① 檢查等差＝相鄰相減都相同　② an=a1+(n−1)d（走 n−1 步）　③ 中項＝平均。

1-2 · 由來

1+2+⋯+100：小高斯的配對法

「級數」就是把數列加起來。傳說高斯小學時老師出 1 加到 100，他幾秒就答出來。

配對：頭尾一組一組抓
1+100 = 101、2+99 = 101、3+98 = 101、…
100 個數配成 50 對，每對 101 → 總和 = 101 × 50 = 5050
等差數列「頭尾等距的兩項，和都一樣」——這個對稱性就是整個 1-2 的引擎。
奇數項也成立嗎？——把級數倒過來寫一次
Sn = a1 + a2 + ⋯ + an；倒著再寫：Sn = an + an−1 + ⋯ + a1
上下相加：2Sn = (a1+an) + (a2+an−1) + ⋯ 每一組都等於 (a1+an)，共 n 組
→ 2Sn = n(a1+an) → Sn = n(a1+an)/2
這個推導不管 n 是奇數或偶數都成立——配對法怕奇數「中間剩一個」，倒寫相加法沒有這個問題。驗證：1+2+⋯+99 = 99×100/2 = 4950，中間的 50 沒有被漏掉。
Sn = n × (首項 + 末項) ÷ 2　＝「項數 ×（頭＋尾）÷ 2」
另一個好記法：Sn = 項數 × 平均，而平均正是 (首項+末項)/2——跟梯形面積公式「(上底+下底)×高÷2」長得一樣不是巧合。
1-2 · 求和公式

兩個版本：知道末項用第一式，不知道用第二式

Sn = n(a1 + an)/2　＝　n[2a1 + (n−1)d]/2
例①【核心必會】3 + 7 + 11 + ⋯ + 39
先確認項數：39 = 3 + (n−1)×4 → n = 10
再套公式：S = 10×(3+39)/2 = 210
題目沒說幾項——項數永遠自己反解，不用猜的。
例②【核心必會】2 + 5 + 8 + ⋯ 共 20 項
不知道末項 → 用第二式：S = 20×[2×2 + 19×3]/2 = 20×61/2 = 610
第二式其實就是先用 an=a1+(n−1)d 把末項算出來、再套第一式——兩式是同一件事。
常見錯：項數不是用「猜」的。像 3、7、⋯、39 的項數要用 an 公式反解：3+(n−1)·4 = 39 → n = 10。先確認項數，再套公式。
例③【進階】不是從第一項開始加：奇數列 1、3、5、…（an=2n−1），求 a5+a6+⋯+a20
法一（當新級數）：項數 = 20−5+1 = 16；a5=9、a20=39 → S = 16×(9+39)/2 = 384
法二（大減小）：S20 − S4 = 400 − 16 = 384 ✓
從中間開始加：項數是「尾 − 頭 + 1」（含頭含尾）；或者用「前 20 項減前 4 項」——注意減的是 S4 不是 S5。
1-2 · 應用與反求

從劇院座位到「加到第幾項」

例①【核心必會】劇院第 1 排 12 個座位，之後每排多 2 個，共 15 排。全部幾個座位？
量對應
首項 a112
公差 d2
項數 n15
S = 15×[2×12 + 14×2]/2 = 15×52/2 = 390 個
應用題先做「翻譯表」：誰是首項、誰是公差、誰是項數，填好再套公式。
例②【進階】等差數列 a1=4、d=3，前 n 項和為 175，求 n
n[8 + 3(n−1)]/2 = 175 → n(3n+5) = 350 → 3n2+5n−350 = 0
十字交乘：(3n+35)(n−10) = 0 → n = 10 或 n = −353
n 是項數，必須是正整數；−35/3 既是負數也不是整數，捨去 → n = 10
反求 n 會出現一元二次方程式——國二上第 4 章在這裡回來了。捨根的標準不是「捨負的」，是「不是正整數就捨」——就算解出正分數也不能當項數。

1-3 · 認識

每次都乘同一個數，就是等比

等比數列（各項皆不為 0）：後項 ÷ 前項 ＝ 固定的數（公比 r，r ≠ 0）
用「除」定義，所以本課討論的數列每一項都不是 0；公比也不為 0（乘 0 一次，後面就全是 0 了）。
例：3、6、12、24、…
6÷3 = 12÷6 = 24÷12 = 2 → 等比數列，公比 r = 2
例：公比可以是分數、也可以是負的
81、27、9、3、…　→ r = 13（越乘越小）
2、−6、18、−54、…　→ r = −3（正負交錯）
5、5、5、…　→ r = 1；5、−5、5、−5、…　→ r = −1（常見觀念題：這兩個都是等比數列）
r 是負數時數列會一正一負跳——看到正負交錯的數列，先猜等比、公比為負。
等差 vs 等比：判斷用「減」還是「除」。5、8、11 相減都是 3 → 等差；3、6、12 相除都是 2 → 等比。兩個都試，別看到數字變大就亂猜。
1-3 · 一般項與中項

an = a1 × rn−1：走 n−1 步，每步乘 r

an = a1 · rn−1　；　a、b、c 均不為 0 時：成等比 ⇔ b2 = ac
例①【核心必會】3、6、12、… 的第 8 項
a8 = 3 × 27 = 3 × 128 = 384
跟等差一樣是 n−1 步——指數是 7 不是 8。
例②【核心必會】等比數列 a2=6、a5=48，求公比與首項
從第 2 項到第 5 項乘了 3 次 r：48 = 6 × r3 → r3 = 8 → r = 2
a1 = 6 ÷ 2 = 3
間隔 3 步是奇數次方，r³=8 只有一個實數解。
例②-2【進階】a2=6、a4=24，求公比與首項
24 = 6r2 → r2 = 4 → r = 2 或 −2（偶數次方，正負都開得回來——第 2 章的平方根）
r=2 時 a1=3；r=−2 時 a1=−3——兩組都是合法答案
間隔偶數步就要想到 ±；間隔奇數步只有一個。跟等比中項的 ± 是同一件事。
例③【進階】4、x、25 成等比數列，求 x
x2 = 4 × 25 = 100 → x = ±10
已知兩端 a、c 且 ac ＞ 0 時，中間項 b = ±√(ac)——但要代回檢查公比是否成立。本題兩個都行：4、10、25 公比 52；4、−10、25 公比 −52。只答 10 會被扣。這裡用到國二上第 2 章的平方根。
1-3 · 生活應用

翻倍的世界：細菌、摺紙、利息

例①【核心必會】2、−6、18、−54、… 求第 6 項
r = −3 → a6 = 2 × (−3)5 = 2 × (−243) = −486
負公比代次方一定加括號：(−3)5 = −243；寫成 −35 會跟「先平方再加負號」混淆（第1章的老朋友）。奇數次方保持負、偶數次方變正。
例②【核心必會】培養皿有 5 隻細菌，每小時數量變 3 倍。4 小時後有幾隻？
每小時 ×3 → 4 小時後 = 5 × 34 = 5 × 81 = 405 隻
「n 小時後」乘了 n 次——這裡跟一般項的 n−1 不同，因為「現在」是第 0 時、不是第 1 項。看清楚題目從哪裡開始數。
例③【進階】利息：本金 10000 元，每年增加 2%，3 年後本利和？
每年變成原來的 1 + 2% = 1.02 倍 → 3 年後 = 10000 × 1.023 ≈ 10612 元
這題的重點只有一個：認出公比是 1.02（不是 0.02）。「增加 2%」= 乘 1.02。
1-3 三件武器：① 判斷等比＝相鄰相除都相同（r≠0）　② an=a1·rn−1　③ 等比中項 b²=ac（答案有 ±）。
